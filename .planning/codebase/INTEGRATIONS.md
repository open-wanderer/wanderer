# External Integrations

**Analysis Date:** 2026-06-07

## APIs & External Services

**Geospatial Services:**
- **Valhalla** - Routing and elevation profile service
  - SDK/Client: Custom HTTP client in `web/src/lib/server/valhalla.ts`
  - Use: Route calculation, elevation profiles, path optimization
  - Config: `VALHALLA_URL` env var
  - Endpoints: Used via `web/src/routes/api/v1/valhalla/route/+server.ts` and `web/src/routes/api/v1/valhalla/height/+server.ts`
  - Default: https://valhalla1.openstreetmap.de (can be self-hosted)

- **Nominatim** - Reverse geocoding and place search
  - SDK/Client: Custom HTTP client in `web/src/lib/server/nominatim.ts`
  - Use: Address lookup, place name resolution
  - Config: `NOMINATIM_URL` env var
  - Rate Limiting: 1000ms between requests to OpenStreetMap's public instance
  - Retries: 2 attempts on failure
  - Default: https://nominatim.openstreetmap.org

- **Overpass API** - OpenStreetMap data queries
  - SDK/Client: Custom HTTP client in `web/src/lib/server/overpass.ts`
  - Use: Query POIs, trails, and geographic features from OSM
  - Config: `OVERPASS_API_URL` env var
  - Retries: 2 attempts on failure
  - Default: https://overpass-api.de

- **OpenStreetMap Tiles** - Map tile layers
  - Use: Base map rendering via MapLibre GL
  - Integration: `web/src/lib/components/trail/map_with_elevation_maplibre.svelte`
  - No authentication required for standard tiles

## Data Storage

**Databases:**

- **PocketBase** (Custom flomp/wanderer-db container)
  - Type: SQL backend (SQLite) with API layer
  - Version: 0.26.8 (via SDK)
  - Collections: users, trails, waypoints, summits, comments, settings, activitypub_actors, api_tokens
  - Connection: `web/src/lib/pocketbase.ts` (client-side), `web/src/hooks.server.ts` (server-side)
  - Auth: Cookie-based auth with token refresh
  - Encryption Key: `POCKETBASE_ENCRYPTION_KEY` env var
  - Client: `pocketbase` SDK (0.26.8)
  - Features:
    - User authentication with OAuth2 provider support
    - Role-based access control
    - Real-time subscriptions
    - File attachments
  - Env vars: `PUBLIC_POCKETBASE_URL` (public), connection established in hooks
  - Docker: `flomp/wanderer-db:latest` (custom image with migrations)

- **Meilisearch** (Container)
  - Type: Full-text search engine
  - Version: v1.36.0 (Docker container)
  - Purpose: Fast search across trails, waypoints, locations
  - Connection: `web/src/hooks.server.ts` (instantiated per-request with user token)
  - Client: `meilisearch` SDK (0.57.0)
  - Auth: Token-based (tenant-scoped tokens generated by PocketBase via `/search/token` endpoint)
  - Token Management: Cookies with format `{token}|{userId}` for identity validation
  - Env vars: `MEILI_URL`, `MEILI_MASTER_KEY` (Docker only)
  - Docker: `getmeili/meilisearch:v1.36.0`

- **ObjectBox** (Mobile local database)
  - Type: NoSQL object database
  - Version: 5.3.1
  - Location: `app/pubspec.yaml`
  - Purpose: Local data storage on mobile device
  - Features: Fast queries, transactions, relations
  - Generated: Code generation via `objectbox_generator` build runner

**File Storage:**
- **Local filesystem** - File uploads directory mounted via Docker volume
  - Path: `/app/uploads` in container, mapped to `./data/uploads` on host
  - Upload handling: Environment variables `UPLOAD_USER`, `UPLOAD_PASSWORD` (for optional basic auth)
  - Body size limit: Configurable via `BODY_SIZE_LIMIT` env var (set to `Infinity` in compose)
  - Trail attachments, profile images, and GPX uploads stored here

**Caching:**
- **None detected** - No explicit caching layer (Redis, Memcached)
- **Cookie-based session caching** - Auth tokens and search tokens cached in cookies

## Authentication & Identity

**Auth Provider:**
- **PocketBase built-in authentication**
  - Email/password authentication via PocketBase
  - OAuth2 provider support (configured in PocketBase admin panel)
  - Available providers queried via `web/src/routes/api/v1/auth/oauth/+server.ts`
  - Redirect flow: `POST /api/v1/auth/oauth` with `{name, code, codeVerifier}`
  
- **API Token Authentication**
  - Format: `Bearer wanderer_key_*` tokens
  - Endpoint: `web/src/routes/api/v1/api-token/+server.ts` (CRUD operations)
  - Server-side validation: `web/src/hooks.server.ts` intercepts Authorization header
  - Validation endpoint: `POST /auth/token` on PocketBase
  - Token storage: User can list/revoke via API
  - Schema: `web/src/lib/models/api/api_token_schema.ts`

**Mobile Authentication:**
- Flutter app uses same PocketBase backend
- Cookie jar for persistent session storage (`cookie_jar`, `dio_cookie_manager`)
- HTTP client: `dio` 5.9.2 with cookie manager integration

**Authorization:**
- Route protection via `web/src/lib/util/authorization_util.ts`
- Protected routes redirect unauthenticated users to `/login?r={original_path}`
- CSRF protection on form submissions (allows `/api/v1` paths)

## Environment Configuration

**Required env vars:**
- **Web/Public:**
  - `PUBLIC_POCKETBASE_URL` - Backend URL (e.g., `http://db:8090`)
  - `PUBLIC_DISABLE_SIGNUP` - Boolean to disable registration
  - `PUBLIC_PRIVATE_INSTANCE` - Boolean for private deployment

- **Web/Private (server-side only):**
  - `MEILI_URL` - Meilisearch URL (e.g., `http://search:7700`)
  - `ORIGIN` - Application origin for OAuth redirects
  - `VALHALLA_URL` - Routing service (defaults to OpenStreetMap's)
  - `NOMINATIM_URL` - Geocoding service (defaults to OpenStreetMap's)
  - `OVERPASS_API_URL` - Data API (defaults to overpass-api.de)
  - `UPLOAD_FOLDER` - Directory for file uploads
  - `UPLOAD_USER` - Optional basic auth username for uploads
  - `UPLOAD_PASSWORD` - Optional basic auth password for uploads
  - `BODY_SIZE_LIMIT` - Request body size (set to `Infinity` for uploads)
  - `POCKETBASE_ENCRYPTION_KEY` - Database encryption (PocketBase container)
  - `MEILI_MASTER_KEY` - Meilisearch admin key (container only)
  - `MEILI_NO_ANALYTICS` - Disable analytics (set to "true" in compose)

- **Mobile:**
  - Server URL configuration (likely hardcoded or in config)

**Secrets location:**
- `.env` files (not committed) loaded by Vite at build time
- Docker Compose environment variables (production secrets in `docker-compose.yml` or override files)
- `.gitignore` excludes `.env` and sensitive files
- PocketBase encryption key isolated to database container
