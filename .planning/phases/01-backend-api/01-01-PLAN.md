<objective>
Build the authenticated SvelteKit endpoint `POST /api/v1/valhalla/navigate`. It accepts a Flutter-friendly request (`{ waypoints: [{lat, lon}], costing? }`), calls Valhalla `/route` with `directions_type: "instructions"`, and transforms the upstream response into a compact contract: a `maneuvers` array (each with `instruction`, `length`, `begin_shape_index`, `bearing`) plus a `shape` array of decoded `[lat, lon]` points.

This is the complete vertical slice for Phase 1: a POST request in produces a structured maneuver list out, gated by auth, with descriptive 4xx/502 errors so bad input never yields a 500.

Purpose: Phase 2 (Flutter navigation screen) calls this endpoint at navigation start to drive turn-by-turn maneuver display. The endpoint abstracts Valhalla's leg-centric format behind a flat, Flutter-consumable contract (per D-04, D-05, D-07).
Output: One new endpoint file, one new Zod schema file, type additions to the existing Valhalla model, and a Vitest test suite.
</objective>

</phase_goal>
