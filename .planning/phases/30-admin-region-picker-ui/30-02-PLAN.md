## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| admin browser -> PATCH /api/collections/regions/records/{id} | The only state mutation in the phase; authenticated by the explicit superuser JWT Authorization header |
| already-fetched leaf `path` values -> region_polygons OR-filter string | Path strings are interpolated into a PocketBase filter expression |
| region_polygons `polygon` GeoJSON + server error `message` -> map / DOM | Server-returned data is rendered (map geometry, inline error text) |
| admin browser -> tiles.openfreemap.org (external CDN) | Map style/tiles/glyphs/sprite fetched cross-origin (allowed by 30-01's widened CSP) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-30-06 | Tampering | PATCH body `{ enabled }` on the toggle | mitigate | Send ONLY a literal JS boolean for `enabled` (JSON.stringify({enabled: row.enabled})); never interpolate free text. PocketBase's BoolField schema validation on `regions` rejects non-boolean values server-side; the filter box (D-08, client-only substring) never touches this request. |
| T-30-07 | Spoofing / CSRF | cross-site forgery of the toggle PATCH | mitigate | PocketBase's REST API authenticates via an explicit `Authorization: <JWT>` header that browsers never auto-attach (unlike cookies); a cross-site page cannot read the same-origin localStorage token, so it cannot forge an authorized PATCH. No cookie-session CSRF surface exists. |
| T-30-08 | Tampering / Injection | region_polygons OR-filter built from `path` values | mitigate | The filter is assembled ONLY from `path` values already fetched from the trusted, server-validated `regions` collection (maintainer-curated CoMaps seed), NOT from the free-text filter box; single quotes in each path are escaped before interpolation; chunking keeps each filter under the 3500-char cap so no request is silently rejected. |
| T-30-09 | Tampering / Information Disclosure | server error `message` + region name rendered inline | mitigate | The inline row-error text (which may append the server's `data.message`) and all region names/paths are bound with Alpine `x-text` (auto-escaped), never `x-html` — enforced by the `grep -c 'x-html' == 0` gate. |
| T-30-10 | Information Disclosure / Denial (map function) | external tiles.openfreemap.org dependency under CSP | accept | Map rendering depends on the public OpenFreeMap CDN (D-04 explicitly rejected vendoring a local copy); its outage degrades only the map pane, not toggling/persistence. CSP scopes the allowed origin to exactly tiles.openfreemap.org (no wildcard) so a compromised-CDN blast radius is bounded to this admin-only page. No API key or secret is exposed to the CDN. |
| T-30-SC | Tampering | package-manager installs | accept | N/A this plan — no npm/go/pip installs; MapLibre GL JS 5.24.0 is a version-pinned unpkg CDN tag (matches web/package-lock.json), added in 30-01 (30-RESEARCH.md Package Legitimacy Audit). |
</threat_model>
