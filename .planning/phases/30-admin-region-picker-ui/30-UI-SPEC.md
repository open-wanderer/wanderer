## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps inside a tree row, badge internal padding |
| sm | 8px | Compact gaps (filter-input icon offset, tree row internal gaps) |
| md | 16px | Depth-indent step in the tree (each nesting level indents `+16px`), default card/pane padding |
| lg | 24px | Pane padding, section spacing inside the map/tree split |
| xl | 32px | Layout-level gaps |
| 2xl | 48px | Major section breaks (not expected to be used inside this page — it has no long-form vertical layout) |
| 3xl | 64px | Not used on this page |

Exceptions (inherited verbatim from `federation_ui.html` — reuse for shared shell elements, do **not** introduce further odd values for phase-30 additions):

- `38px` — app-header height
- `36px` — `.input` / `.btn` height, and the new **tree row height** (kept identical for rhythm with the shell's inputs/buttons)
- `30px` — `.btn-sm` height
- **Toggle switch**: `36px × 20px` track, `16px` thumb diameter — standard switch proportions (not on the 4px grid by width:height ratio, but each dimension is itself a multiple of 4). This is the one net-new sizing exception this phase introduces.
- **Tree indentation**: `8px` base left-padding + `16px` (`md`) per depth level (depth 0/1/2 → `8px`/`24px`/`40px` left padding before the chevron)

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 (regular) | 1.5 |
| Label | 12px | 600 (semibold) | 1.4 |
| Heading | 16px | 600 (semibold) | 1.3 |
| Display | 19px | 600 (semibold) | 1.2 |

- **Body (14/400/1.5)** — tree row region names, map overlay copy, filter input text, table/body text generally. This is the `<body>` element default in the canonical reference — do not override per-component.
- **Label (12/600/1.4)** — badges (`.count-badge`, enabled-count pill), `.card-section-title`-style uppercase micro-labels, tree filter placeholder, `.btn-sm` text.
- **Heading (16/600/1.3)** — pane headers ("Region Catalog" tree pane title if used), modal titles (none in this phase — no destructive confirmations), any sub-section heading.
- **Display (19/600/1.2)** — the page `<h1>` ("Region Catalog"), matching the canonical reference's `.page-title h1`.

Two weights declared: **400 regular** and **600 semibold**. `500 (medium)` is loaded by the inherited Google Fonts `@import` (`wght@400;500;600`) but is a **legacy-only exception** — it appears in the canonical reference on `.header-label` and `.domain-cell`-equivalent emphasis text. Do not reach for `500` on any new phase-30 element (tree rows, toggle, filter, map overlays); use `400` or `600` only.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--bg)` — `#ffffff` light / `#1f1f1f` dark | Page background, map pane background before tiles load |
| Secondary (30%) | `var(--surface)` / `var(--surface2)` — `#f8f9fa`/`#e4e8ec` light, `#232323`/`#2f2f2f` dark | Tree pane background, `.card` bodies, tree-row hover state, toggle track (off state) |
| Accent (10%) | `var(--accent)` — dynamic, read from the logged-in admin's own PocketBase `accentColor` setting at runtime; falls back to `#1055c9` | See "Accent reserved for" below — this is the **one** color phase-30 spends its 10% budget on |
| Destructive | `var(--danger)` — `#e1473d` | Inline per-row toggle-failure error text only (D-06). **No delete/destroy actions exist in this phase** — enable/disable is fully reversible, so `--danger` is never used on a button or as a confirmation-dialog color here. |

Accent (`var(--accent)`) reserved for, and only for:

1. The page `<h1>` icon (matches the canonical reference's `.page-title h1 i`)
2. Focus rings on the filter `.input` (`box-shadow: 0 0 0 3px var(--accent-fade)`, already established)
3. The toggle switch's **on/enabled** state (track fill)
4. Every enabled-leaf polygon rendered on the live map: fill `var(--accent)` at ~18% opacity, 2px solid `var(--accent)` outline
5. The "N enabled" count badge next to the page title (background `var(--accent-fade)`, text `var(--accent)`)

Do not use accent for group-node chevrons, unselected tree rows, or any other decorative purpose — this keeps the near-monochromatic 60/30/10 discipline the rest of the codebase's admin surfaces already follow.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | **None** — this page has no create/submit flow. The nearest analog is the per-leaf toggle switch itself: `aria-label="Enable {region name}"` when off, `aria-label="Disable {region name}"` when on. |
| Empty state heading | `No regions match "{query}"` — shown in the tree pane when the D-08 filter yields zero matches |
| Empty state body | `Try a different search term.` |
| Error state | `Couldn't update — try again.` shown inline directly under the failed row per D-06 (`.row-error`-equivalent style, `var(--danger)`, 12px). If the server returned a specific reason, append it: `Couldn't update: {reason} — try again.` No dedicated retry button; the reverted toggle is already clickable (per D-06/discussion log). |
| Destructive confirmation | **N/A** — no destructive actions in this phase. Toggling a region `enabled=false` is instantly reversible and takes effect only on the cron's *next* run (ADMINUI-02), so no confirmation dialog is required or wanted. |
| *(supplementary)* Map empty state | When zero leaf regions are currently enabled: overlay text `No regions enabled` / `Toggle a region in the tree to see its boundary here.` Map falls back to a static default view (center `[10, 45]`, zoom `3` — roughly Europe-centered) instead of attempting to fit empty bounds (D-05 only specifies fit-to-enabled-union; this is the required fallback for the zero-enabled case). |

## New Component Contracts (phase-30 additions)

These are not covered by the canonical reference and are specified here since the planner/executor need concrete values, not just tokens.

### Layout
Two-pane split below the reused `.app-header` (38px, sticky): **left pane** = tree, fixed width `380px`, full remaining viewport height, `overflow-y: auto`, background `var(--surface)`, right border `1px solid var(--border)`. **Right pane** = map, `flex: 1`, full remaining viewport height. No page-level max-width cap (unlike the 980px-capped `federation_ui.html` — this page needs the full viewport for the map). Filter input is pinned to the top of the left pane (non-scrolling), tree rows scroll beneath it.

### Filter input
Reuse `.input` class verbatim, prefixed with `ri-search-line` (`var(--text2)`), placeholder `Filter regions…`. Client-side substring match (case-insensitive) against `name`, already-fetched, no network call (D-08). Debounce: **120ms** on keystroke before re-filtering (Claude's Discretion, per CONTEXT.md). On match, ancestor chain auto-expands (D-08); on the tree collapsing back to its default state, cleared filter restores the D-07 auto-expand-if-contains-enabled-leaf state.

### Tree row
Height `36px`, left padding `8px + 16px × depth` before the row's leading icon/chevron, `8px` gap between chevron/label/trailing control, hover background `var(--surface2)` (0.1s transition, matching `.peers-table tbody tr:hover`).

- **Group row** (`kind: "group"`): `ri-arrow-right-s-line` (collapsed) / `ri-arrow-down-s-line` (expanded) chevron, `16px`, `var(--text2)`, click anywhere on the row toggles expand/collapse. `role="treeitem" aria-expanded="{true|false}"`. Name in Body style (14/400).
- **Leaf row** (`kind: "leaf"`): no chevron (no children), name in Body style, trailing **toggle switch** right-aligned (see below). `role="treeitem"`.

### Toggle switch
`36px × 20px` track, `16px` circular white thumb, `2px` inset. Off state: track `var(--surface2)`, `1px solid var(--border)`. On state: track `var(--accent)`, thumb slides to the right, `0.15s` transition (`transform` + `background`). Implemented as `role="switch" aria-checked="{true|false}"`, keyboard-operable (`Space`/`Enter`). Optimistic per D-06: flips instantly on click; on PATCH failure, reverts to prior state and shows the inline row error (Copywriting Contract, above) directly beneath that row.

### Live map (MapLibre GL JS)
- Style: `https://tiles.openfreemap.org/styles/liberty` (D-04) — loaded directly, no local copy.
- On load: fetch `region_polygons` for currently-enabled leaves only (D-03), render each as one `fill` + one `line` layer pair styled per the Color section's accent rules above.
- `fitBounds()` to the union of all enabled leaf `bbox` values on initial load (D-05); padding `48px` on all sides. Falls back to the "Map empty state" default view (Copywriting Contract) when zero leaves are enabled.
- On a toggle flip (optimistic, D-06): add/remove that single region's polygon layer immediately; on PATCH failure, remove/re-add to match the reverted toggle state. No re-`fitBounds()` on individual toggles — only on initial page load (avoids disorienting the admin mid-session).
- Loading indicator while the MapLibre style itself loads: reuse `.spinner-accent` centered over the map pane.
