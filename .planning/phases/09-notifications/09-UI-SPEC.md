# Phase 9 — UI Design Contract

> Visual and interaction contract for the Notifications settings screen. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Stack note:** This is a Flutter + Material 3 project. shadcn does not apply (no React/Next.js/Vite). The design contract is expressed in Flutter `ColorScheme` / `TextTheme` tokens that already exist in `app/lib/theme/`. This phase introduces **no new visual tokens** — it reuses the canonical settings-screen pattern established by `settings_privacy_screen.dart` and `settings_language_screen.dart`.

## Spacing Scale

Declared values (multiples of 4). Only the section-header padding token is used by this screen; `SwitchListTile` supplies its own Material-standard internal padding.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | (n/a this screen) |
| sm | 8px | Section-header bottom padding |
| md | 16px | Section-header left/right/top padding |
| lg | 24px | (n/a this screen) |
| xl | 32px | (n/a this screen) |

**Section header padding (canonical):** `EdgeInsets.fromLTRB(16, 16, 16, 8)` — copied verbatim from `settings_privacy_screen.dart` `_sectionHeader` (CONTEXT D-02).

Exceptions: `SwitchListTile` and `ListView` rows use Material's built-in list-item metrics (≈16px horizontal, ≥48px min row height for touch target). These are framework defaults and are not overridden.

## Typography

All roles map to the existing Material `TextTheme` (IBMPlexSans). This screen declares no custom sizes beyond the inherited theme.

| Role | Size | Weight | Line Height | Token |
|------|------|--------|-------------|-------|
| Section header | 14px | medium (500) | 1.43 (Material default) | `textTheme.titleSmall` + `color: onSurfaceVariant` (CONTEXT D-02) |
| List tile title ("Web" / "Email") | 16px | regular (400) | 1.5 (Material default) | `SwitchListTile` default `titleTextStyle` (`textTheme.bodyLarge`) |
| AppBar title | 22px | medium (500) | 1.27 (Material default) | `AppBar` default `titleLarge` |

Weights in play: regular (400) for list content, medium (500) for headers/AppBar — Material 3 defaults, no overrides.

## Color

This screen consumes the app `ColorScheme` (`app/lib/theme/colors.dart`). Hex values shown for both modes; the executor uses the semantic `colorScheme.*` token, never a literal hex.

| Role | Value (light / dark) | Usage |
|------|----------------------|-------|
| Dominant (60%) | `#FFFFFF` / `#12141C` | `colorScheme.surface` — Scaffold background, ListView surface |
| Secondary (30%) | `#242734` / `#3E435B` | `colorScheme.primary` — AppBar background, switch active track |
| Accent (10%) | `colorScheme.primary` (light) / `colorScheme.onSurface` (dark) | Switch active thumb/track ON state only |
| Destructive | n/a this screen | No destructive action in Phase 9 |
| Section-header text | `colorScheme.onSurfaceVariant` | Muted section descriptions (CONTEXT D-02) |

**Accent reserved for:** the ON state of each `SwitchListTile` (active thumb + track) only. Follow the established active-color rule from the sibling screens:
```dart
final activeColor = Theme.of(context).brightness == Brightness.dark
    ? colorScheme.onSurface
    : colorScheme.primary;
```
Pass `activeColor` (or `activeThumbColor` per current Flutter API) to every `SwitchListTile`. Accent is NOT applied to text, headers, or row backgrounds.

**Note:** `colorScheme.error` is `#FEF2F2` (a background tint, illegible as foreground) — do not use it for any foreground text on this screen. There is no destructive UI here, so it is not needed.

## Copywriting Contract

No CTA button and no empty/destructive states — this is an auto-save toggle list. All visible strings are existing or one new ARB key (no hardcoded literals).

| Element | Copy | Source |
|---------|------|--------|
| Screen title | "Notifications" | `l10n.notifications` (exists) |
| Section header (×9) | The per-type description, e.g. "Someone left a comment on your trail" | `l10n.settings_notification_*` (all 9 exist — CONTEXT D-04, D-05) |
| Web toggle label | "Web" | NEW ARB key `"web": "Web"` — must be added to `app_en.arb` then `flutter gen-l10n` (CONTEXT D-03) |
| Email toggle label | "Email" | `l10n.email` (exists — CONTEXT D-03) |
| Error state (save failure) | "Failed to save settings" (or locale equivalent) | `l10n.error_saving_settings` via error toast (CONTEXT D-08) |
| Primary CTA | none — auto-save on every toggle change, no Save button (CONTEXT D-08) | — |
| Empty state | none — the nine types always render; settings absent ⇒ defaults to `true` per toggle (CONTEXT D-07) | — |
| Destructive confirmation | none — no destructive action in this phase | — |

**Notification type order (CONTEXT D-05), each rendered as: section header → "Web" SwitchListTile → "Email" SwitchListTile:**
1. Trail comments (`trail_comment`)
2. New followers (`new_follower`)
3. Trail shares (`trail_share`)
4. Trail likes (`trail_like`)
5. List shares (`list_share`)
6. Summit log creates (`summit_log_create`)
7. Trail mentions (`trail_mention`)
8. Comment mentions (`comment_mention`)
9. Summit log mentions (`summit_log_mention`)

Total: 9 section headers + 18 `SwitchListTile`s in one `ListView` (CONTEXT D-01).

## Interaction Contract

| State | Behavior |
|-------|----------|
| Toggle ON/OFF | Auto-saves immediately via `settingsProvider.saveToServer(settings.copyWith(notifications: updatedMap))` (CONTEXT D-08, D-09). No confirmation. |
| Default (no saved pref) | Switch renders ON — `settings?.notifications?[key]?.web ?? true` (CONTEXT D-06, D-07) |
| Save failure | Error toast (`ToastType.error`, `FontAwesomeIcons.circleExclamation`, `l10n.error_saving_settings`) — switch reflects watched provider state (CONTEXT D-08) |
| Loading / null settings | Read `ref.watch(settingsProvider)` via `.value` (not `.valueOrNull`) per project memory; guard null before building the updated map (CONTEXT D-11) |
| Back navigation | `AppBar` leading `IconButton(Icons.arrow_back)` → `context.pop()` (CONTEXT D-10) |
| Touch target | `SwitchListTile` provides Material ≥48px row height — meets accessibility minimum |
