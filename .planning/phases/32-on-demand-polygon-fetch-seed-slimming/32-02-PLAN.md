## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| committed artifact -> migration parser | `regions_seed.json` is a trusted in-repo file, but a corrupt or truncated copy must fail loudly rather than half-seed |
| internal writers -> `region_geometry` | any code path creating a geometry row crosses the path-based referential-integrity boundary |
| migration -> network | first boot must have zero outbound dependency (SLIM-04) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-32-05 | Denial of Service (memory blow-up on read) | migration seed reader | accept | The 512 MB `io.LimitReader` bound and the token-by-token decoder retire deliberately: the artifact is a ~292 KB trusted in-repo file read exactly once behind the `CountRecords` guard. Peak heap for `ReadFile` plus `Unmarshal` of 1306 geometry-free rows is well under a megabyte |
| T-32-06 | Tampering (orphan geometry rows) | `region_geometry` writes | mitigate | `ValidateRegionPathReferenceHandler` is rebound to `region_geometry` in Task 2, so a geometry row whose `path` has no matching `regions.path` is rejected at the model-hook layer, covering internal writes as well as API traffic |
| T-32-07 | Tampering (stale collection survives an upgrade) | already-seeded dev boxes | accept | D-05 knowingly ships no defensive drop migration. The `CountRecords("regions")` guard means a seeded box keeps a stale `region_polygons`; Task 3 resets `pb_data` and the SUMMARY records that self-hosters on `feature/app` must do the same. The migration has never been released, so no production fleet is affected |
| T-32-08 | Information disclosure | `regions.catalog_commit` | accept | A public upstream commit SHA is not sensitive; it is already a hardcoded default in `seed_regions.go` |
| T-32-SC | Tampering (dependency supply chain) | npm/pip/cargo/go installs | accept | No package installs in this plan. `db/go.mod` and `db/go.sum` are unmodified; the edit only removes imports |
