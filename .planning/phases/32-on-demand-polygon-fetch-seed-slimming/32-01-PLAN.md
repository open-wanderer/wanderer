<objective>
Collapse `seed-regions` from a ~1153-request polygon scrape into a single `hierarchy.txt` fetch, and make its output a pure-hierarchy, plain, pretty-printed JSON catalog that records the CoMaps commit SHA it came from (SLIM-01, per D-00a, D-00b, D-12). With the generator no longer converting `.poly` files, relocate `ParsePoly` out of package `commands` into package `regions`, where this phase's runtime fetch path consumes it — avoiding the `services/regions -> commands` dependency the Phase 28 migration explicitly refused.

Purpose: the committed catalog drops from 54.65 MB gzipped to ~292 KB of reviewable plain JSON, and a maintainer refresh drops from a multi-minute, retry-prone scrape to about a second.
Output: a slimmed `seed_regions.go`, `ParsePoly` living in `db/services/regions/`, and a regenerated `db/migrations/initial_data/regions_seed.json`.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| maintainer CLI flag -> outbound URL | `--commit` is operator-supplied text interpolated into a third-party raw-file URL |
| CoMaps upstream -> generator memory | `hierarchy.txt` bytes are untrusted third-party input parsed by `ParseHierarchy` |
| generator output -> committed repo artifact | the emitted JSON becomes a trusted in-repo file consumed by the first-boot migration |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-32-01 | Tampering (SSRF/path traversal) | `SeedRegions` `--commit` -> `baseURL` | mitigate | Keep the existing `commitHashPattern` allow-list `^[0-9a-f]{7,40}$` and its `log.Fatalf` gate ahead of any URL construction (T-28-03 lineage); host is a hardcoded constant per D-04, never env-configurable |
| T-32-02 | Denial of Service (unbounded response) | `fetch(baseURL+"hierarchy.txt", 8<<20)` | mitigate | Keep the `io.LimitReader(resp.Body, maxBytes)` bound in `doFetch` at the existing 8 MB cap (T-28-04 lineage); do not remove it while removing the gzip layer |
| T-32-03 | Denial of Service (parser blow-up) | `ParseHierarchy` on hostile input | mitigate | Unchanged parser; returns descriptive errors and never aborts the process. Relocating `ParsePoly` changes no parsing logic, so its 16 MB scanner buffer bound is preserved verbatim |
| T-32-04 | Tampering (supply-chain of committed data) | `regions_seed.json` | mitigate | The artifact records the exact pinned commit it was generated from (D-00b), so a reviewer can reproduce it; the diff is now plain reviewable JSON instead of an opaque 55 MB binary blob |
| T-32-SC | Tampering (dependency supply chain) | npm/pip/cargo/go installs | accept | No package installs in this plan. `db/go.mod` and `db/go.sum` are not modified; every change uses stdlib plus already-vendored deps. Verify with `git diff --name-only` showing no `go.mod`/`go.sum` entry |
