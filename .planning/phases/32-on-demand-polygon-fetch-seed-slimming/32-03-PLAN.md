Create `db/services/regions/geometry_fetch.go` in package `regions`.

Host constants, hardcoded per D-04 — no env var, no injectable seam, because D-06 means nothing needs to redirect the fetcher in tests. Define `comapsGitHubRawBase = "https://raw.githubusercontent.com/comaps/comaps"` and `comapsCodebergRawBase = "https://codeberg.org/comaps/comaps/raw/commit"`. Document that GitHub is primary because Codeberg's raw endpoint enforces a roughly 250-requests/600s quota, that the quota is irrelevant to a single on-demand leaf fetch, and that Codeberg is CoMaps' canonical home while GitHub is the mirror.

Allow-lists, evaluated before any URL is built. Define `catalogCommitPattern` as `^[0-9a-f]{7,40}$`, mirroring `commandHashPattern`'s role in T-28-03 but declared locally so no cross-package dependency is introduced. Define `comapsIDPattern` as `^[A-Za-z0-9][A-Za-z0-9 _'-]*$`, grounded in the verified character set of the live catalog: it admits every real leaf id while structurally excluding `/`, `\`, `%`, `.` and therefore `..`, so a hostile or corrupted `comaps_id` cannot escape the `/data/borders/` prefix.

Exported pure function `PolySourceURLs(commitSHA, comapsID string) ([]string, error)`. It validates both inputs against the patterns above, returning a descriptive error naming which input failed, and otherwise returns exactly two URLs in fallback order: the GitHub mirror first, Codeberg second. Both are built as base plus `/` plus the commit plus `/data/borders/` plus `url.PathEscape(comapsID)` plus `.poly`. Keeping this pure and exported is what makes the fallback ordering unit-testable under D-06 without touching the network.

Internal single-host fetch. Write `fetchPolyBytes(rawURL string) ([]byte, error)` following `doFetch`'s structure: HTTP GET, close the body, treat 429 as retryable using a `Retry-After` parse, treat any other non-200 as a descriptive non-retryable error, and read the body through `io.ReadAll(io.LimitReader(resp.Body, maxPolyBytes))` with `maxPolyBytes = 32 << 20` — the same bound the generator used, preserved verbatim so removing the seed does not remove the response-size guard. Use a package-level `var polyHTTPClient = &http.Client{Timeout: 15 * time.Second}` rather than `http.Get`, matching `db/federation/activity.go`'s bounded-client convention.

Retry budget, tightened per D-03. Define `polyFetchAttempts = 2` and `polyFetchRetryCap = 5 * time.Second`. A 429 sleeps for the smaller of the parsed `Retry-After` and `polyFetchRetryCap` before the single retry. Do not reuse `seed_regions.go`'s `maxFetchRetries = 10` with 30-second sleeps: this runs synchronously inside a per-region cron build across roughly 100 regions and inline in an HTTP request handler, so worst-case time per region must stay bounded at roughly 80 seconds across both hosts rather than tens of minutes. Add a comment stating that budget arithmetic explicitly.

Pure failure-message composer. Write `describePolyFetchFailure(urls []string, lastErr error) error` which returns an error whose text names every attempted upstream host and wraps `lastErr` with `%w`. The D-01 and ROADMAP requirement is that a failure names which upstreams were tried, and keeping this pure makes that assertable in a unit test with no network.

Exported entry point `FetchGeometry(commitSHA, comapsID string) (map[string]any, [4]float64, error)`. Call `PolySourceURLs`, propagating a validation error unchanged. Walk the URLs in order, calling `fetchPolyBytes` with the retry budget; on the first success, return `ParsePoly(data)` directly so geometry and bbox both come from the single canonical parser. If every URL fails, return `describePolyFetchFailure`. If `ParsePoly` itself fails on bytes that were successfully fetched, return that parse error wrapped with the region id — do not fall through to the other host, because a parse failure means the content is malformed rather than the host being unavailable.

Add no `httptest` coverage and no injectable transport. D-06 is a deliberate decision recorded so this is not "helpfully" restored later; the network layer is verified manually in Task 3.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| catalog data -> outbound URL | `comaps_id` and `catalog_commit` originate from a third-party upstream file and are interpolated into a request URL |
| CoMaps upstream -> server memory | `.poly` response bytes are untrusted third-party input parsed in-process |
| Wanderer server -> CoMaps hosts | outbound request volume and retry behaviour are visible to a third party and rate-limited by them |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-32-09 | Tampering (SSRF / path traversal) | `PolySourceURLs` | mitigate | `comapsIDPattern` `^[A-Za-z0-9][A-Za-z0-9 _'-]*$` excludes `/`, `\`, `%` and `.`, so `..` is unrepresentable; `url.PathEscape` is applied on top; the host is a hardcoded constant with no env override (D-04). Verified against the full live catalog's character set |
| T-32-10 | Tampering (SSRF via commit) | `PolySourceURLs` | mitigate | `catalogCommitPattern` `^[0-9a-f]{7,40}$` rejects `main`, `../`, uppercase and empty before interpolation, matching the `commitHashPattern` allow-list precedent set for T-28-03 |
| T-32-11 | Denial of Service (unbounded response) | `fetchPolyBytes` | mitigate | `io.ReadAll(io.LimitReader(resp.Body, 32<<20))` preserves the T-28-04 bound verbatim, plus a 15-second `http.Client` timeout so a slow-loris upstream cannot pin a cron goroutine or a request handler |
| T-32-12 | Denial of Service (retry amplification against a third party) | retry budget | mitigate | D-03's tight budget: 2 attempts per host with a 5-second sleep cap, versus the generator's 10 retries at 30 seconds. | T-32-14 | Information disclosure | fetched boundary geometry | accept | CoMaps boundary data is public, ODbL-licensed OSM-derived content; no secret or user data crosses this seam |
| T-32-SC | Tampering (dependency supply chain) | npm/pip/cargo/go installs | accept | No package installs in this plan. `db/go.mod` and `db/go.sum` are unmodified; the implementation uses only stdlib `net/http`, `net/url`, `io`, `regexp` and `time` |
