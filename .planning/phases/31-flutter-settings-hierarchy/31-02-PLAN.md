<objective>
Convert `settings_offline_regions_screen.dart` from a flat `ListView.separated` to a collapsible hierarchy (D-01): build the tree once per genuine catalog fetch, cache tree shape + expand state in `State` (never rebuild it on a download/progress provider tick — Pitfall 1), join live `RegionEntity` data in at render time, and render group rows + indented leaf rows via `ListView.builder` over `flattenVisible`. Preserve every existing per-region Vector/DEM action and the disk-usage summary unchanged (APPUI-02), add the offline empty state (D-04), and wire filter to the ported `computeFilterMatches` (D-06).

Purpose: This is the user-visible deliverable of Phase 31 — the app's region list becomes the same hierarchy the admin defines, with zero download-UX regression except the deliberately-scoped offline empty state (D-04).
Output: New ARB keys across all locales, the rewritten screen build/state, one new group-row widget, and a new widget test file.
</objective>
