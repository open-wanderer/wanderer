<objective>
Build the two cluster-rendering primitives `map_screen` (16-03) wires together: a new `MapClusterSearch` provider that hits the server-side cluster endpoint, and a `cluster_layer.dart` builder that ports web's `clusters`/`cluster-count` style layers verbatim into native MapLibre layers. This plan produces both halves in isolation so 16-03 is pure wiring.
Output: `map_cluster_search_provider.dart` (+ generated part), `cluster_layer.dart`.
