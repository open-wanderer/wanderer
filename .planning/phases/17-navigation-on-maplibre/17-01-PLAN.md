<objective>
Migrate `navigation_screen.dart`'s map-rendering layer from `flutter_map` to
native `ml.MapLibreMap`, replacing the four `flutter_map`-only dependencies
(`AnimatedMapController`, `CurrentLocationLayer`/`LocationMarkerDataStreamFactory`,
the app-local `MapCompass`, and `MultiPmTilesVectorTileProvider`) with the
`maplibre` 0.3.5 APIs Phase 15/16 already proved on-device. The turn-by-turn UI
(maneuver banner, stats sheet, button row, waypoint sheet, elevation page) is
UNCHANGED — only the map widget block and its supporting plumbing change.

Purpose: Move the app's last `flutter_map` screen onto native GL so heading-up
follow, compass reset, and a live location puck run through `enableLocation`/
`trackLocation`/`animateCamera`/`ml.MapCompass` (NAV-01/02/03, CORE-06/07), and
so offline navigation renders its basemap from local `.pmtiles` (NAV-04 basemap).

Output: A rewritten map section in `app/lib/routes/navigation_screen.dart` that
builds (`flutter analyze` clean) with no `flutter_map`/`vector_map_tiles` imports,
and leaves the existing unit suite green (maneuver + offline-rewrite logic
untouched).
</objective>
