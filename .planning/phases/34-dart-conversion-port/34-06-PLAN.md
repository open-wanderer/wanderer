<objective>
Make `showTrackSaveOptionsSheet` the single post-capture gate for all three capture sources,
shown only when online, skipped entirely when offline (D-15) - which fixes in passing the real
defect where finishing a planned route offline strands the user on the planner behind an error
toast (D-16).

Purpose: the recording path already has this gate; the planner corrects elevation unconditionally
and dead-ends offline, and the import path never corrects at all. One shared helper unifies the
three and removes the last blocker to completing a capture with no connection.

Output: `app/lib/util/track_save_options_util.dart` with `resolveTrackSaveOptions`, all three call
sites routed through it, and the planner's post-capture transforms applied per leg so the route's
`trkseg` structure survives.
</objective>
