## Why this is a NEW file and NOT an extension on `Gpx` (D-17 / Pitfall 5)

`app/lib/util/gpx_util.dart` already carries a `GpxMappingUtils.getTotals()` extension with the
identical CONV-01 defect (`for (int i = 1; ...)`), no defer-then-publish filter, and raw (not
smoothed) distance. It is live, consumed by `elevation_profile.dart:178` and
`trail_panel.dart:44`. It is retired in plan 34-04 — **not here**. Naming anything in this new
module `getTotals` would collide in spirit and produce two same-named functions with different
correctness. The new public entry point is `computeTrailMetrics`.
