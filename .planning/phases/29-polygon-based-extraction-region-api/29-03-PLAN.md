<objective>
Keep the SvelteKit proxy's `RegionIdSchema` in lockstep with the Go `regionIDPattern` relaxed in 29-01, and document the new hierarchy fields on the `GET /api/v1/regions` OpenAPI schema (EXTRACT-03, client-facing surface).

Purpose: `region_archives.region_id` (and therefore the `{id}` path param on the download routes) now stores a seeded materialized `path`, 29 of which contain `.` or an apostrophe (Pitfall 1). The two SvelteKit download proxies validate `{id}` with a Zod regex that is a second, independent copy of the Go allow-list; if it is not relaxed in lockstep, those regions' downloads 400 at the proxy before ever reaching the Go handler. The listing proxy is a pure pass-through — its only change is the OpenAPI doc block that advertises the new fields.

Output:
- `web/src/routes/api/v1/regions/[id]/download/+server.ts` and `.../download-dem/+server.ts` — `RegionIdSchema` regex relaxed to `^[a-z0-9][a-z0-9_.'-]*$` plus a `.refine` rejecting any `..`.
- Their `server.test.ts` files — a case proving a `.`-containing id is accepted (and, for at least one, that a `..` id is rejected).
- `web/src/routes/api/v1/regions/+server.ts` — swagger doc updated with `parent`, `path`, `depth`, `kind`, `enabled`.
</objective>
