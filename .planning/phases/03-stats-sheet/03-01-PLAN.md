    Define `@riverpod class NavigationStatsNotifier extends _$NavigationStatsNotifier` family-keyed on NavigateResponse (mirror Navigation in navigation_provider.dart). Private fields: `final _distance = const Distance();`, `Timer? _ticker;`, `DateTime? _start;`, `Duration _pausedAccum = Duration.zero;`, `DateTime? _pauseStart;`, `double? _lastAltitude;`, `LatLng? _lastPoint;`. Named constant `static const _kAltitudeNoiseFloorMeters = 2.0;` (A1 — tunable noise floor per Pitfall 2).
    build(NavigateResponse response): register `ref.onDispose(() => _ticker?.cancel());` (Pitfall 5) and return `const NavigationStats()`.
    onPosition(Position pos): if isPaused, set state currentSpeedKmh to 0 and return (do not accumulate). On first call set `_start ??= DateTime.now()` and start `_ticker ??= Timer.periodic(const Duration(seconds: 1), (_) => _tick())`. Convert to LatLng(pos.latitude, pos.longitude); if _lastPoint != null add `_distance.as(LengthUnit.Meter, _lastPoint!, here)` to distance; set _lastPoint. For altitude: if _lastAltitude != null and `(pos.altitude - _lastAltitude!).abs() >= _kAltitudeNoiseFloorMeters` then add positive delta to gain or absolute negative delta to loss AND update _lastAltitude; if _lastAltitude == null set it.     _tick(): if isPaused or _start == null return; elapsed = DateTime.now().difference(_start!) - _pausedAccum; avg = elapsed.inSeconds > 0 ? distanceMeters / elapsed.inSeconds * 3.6 : 0.0; state = state.copyWith(elapsed: elapsed, averageSpeedKmh: avg).
    togglePause(): when entering pause set _pauseStart = DateTime.now(), state.copyWith(isPaused:true, currentSpeedKmh:0); when resuming add `DateTime.now().difference(_pauseStart!)` to _pausedAccum, null out _pauseStart, AND reset `_lastPoint = null; _lastAltitude = null;` so the next fix re-anchors (Pitfall 6 — no resume jump), then state.copyWith(isPaused:false).

Cover every behavior case. For pause/resume distance/elevation accumulation use direct onPosition calls (do not rely on the 1s timer for distance assertions); the elapsed-timer tick is time-based and need not be asserted with real delays.
