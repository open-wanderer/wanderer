```go
func LoadLocalPlugin(dir string) (*LocalPlugin, error) {
	manifestPath := filepath.Join(dir, "plugin.json")
	data, err := os.ReadFile(manifestPath)
	if err != nil {
		return nil, err
	}

	var manifest Manifest
	if err := json.Unmarshal(data, &manifest); err != nil {
		return nil, fmt.Errorf("parse plugin.json: %w", err)
	}
	// ...
}
```

**Divergence required (per D-05):** unlike `LoadLocalPlugin`, missing/empty file must return an empty catalog, not an error. The "no file / no env var" branch is new — mirror `DiscoverLocalPlugins`'s `os.IsNotExist` handling instead (manifest.go lines 65-70):
```go
if _, err := os.Stat(dir); err != nil {
	if os.IsNotExist(err) {
		return []LocalPlugin{}, nil, nil
	}
	return nil, nil, err
}
```
Combine both precedents: `os.Getenv` empty → empty catalog; `os.IsNotExist` → empty catalog; any other read error → real error; empty file bytes → empty catalog; then `json.Unmarshal`.

### `db/services/regions/staleness.go` (utility, transform)

**Analog:** `db/services/tiles/generator.go` — `getValidProtomapsURL`/`urlExists` (lines 126-145)

```go
func getValidProtomapsURL() string {
	now := time.Now().UTC()

	todayURL := fmt.Sprintf("https://build.protomaps.com/%s.pmtiles", now.Format("20060102"))
	if urlExists(todayURL) {
		return todayURL
	}

	yesterdayURL := fmt.Sprintf("https://build.protomaps.com/%s.pmtiles", now.AddDate(0, 0, -1).Format("20060102"))
	return yesterdayURL
}

func urlExists(url string) bool {
	resp, err := http.Head(url)
	if err != nil {
		return false
	}
	defer resp.Body.Close()
	return resp.StatusCode == http.StatusOK
}
```
**Required change per D-10 / Pitfall 4:** this function returns only a URL, but the region builder needs the bare `YYYYMMDD` string to persist and compare on each cron tick. Add a companion function (do not change the existing per-cell caller's signature) that returns `(date string, url string)`, e.g.:
```go
func ValidProtomapsDateAndURL() (date string, url string) {
	now := time.Now().UTC()
	today := now.Format("20060102")
	todayURL := fmt.Sprintf("https://build.protomaps.com/%s.pmtiles", today)
	if tiles.URLExists(todayURL) { // export urlExists or duplicate locally
		return today, todayURL
	}
	yesterday := now.AddDate(0, 0, -1).Format("20060102")
	return yesterday, fmt.Sprintf("https://build.protomaps.com/%s.pmtiles", yesterday)
}
```
