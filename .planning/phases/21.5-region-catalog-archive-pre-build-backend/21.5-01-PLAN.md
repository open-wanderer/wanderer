<objective>
Establish the data contract for the region catalog backend: a JSON config loader that reads this instance's admin-defined regions (id, name, bbox) tolerantly, path-safety validation for the untrusted-ish region id, and the `region_archives` PocketBase collection that tracks each region's build state. This is the foundation every downstream plan (builder, API endpoint) consumes.

Purpose: Downstream plans need one shared `Region` type, one validated path builder, and one persistence schema before any build or serve logic can exist. Getting the "missing/empty config → empty catalog, not an error" contract (D-05) and the id path-traversal guard (D-03 / Pitfall 7) right here prevents a startup-crash class and a filesystem-traversal class of bug from propagating.

Output: `db/services/regions/config.go` (+ tests) and the `region_archives` collection migration.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| admin config file → Go filesystem paths | The Docker-mounted JSON is operator-supplied but its `id` field flows into `filepath.Join(pb_data/region_archives/{id}/...)`; treated as attacker-adjacent (defense in depth) |
| admin config file → `pmtiles extract` args | bbox floats will (in Plan 02) be interpolated into a subprocess argument; validated as numeric + range here at load time |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-21.5-01 | Tampering | region `id` → `filepath.Join` in RegionArchivePath/RegionDemPath | mitigate | Allow-list regex `^[a-z0-9][a-z0-9_-]*$` (regionIDPattern) enforced in ValidateRegion at load time AND exposed via IsValidRegionID for the route to re-check the untrusted URL param in Plan 03; entries failing it are skipped, not fatal (config errors never crash startup per BACK-01) |
| T-21.5-02 | Tampering | bbox floats bound for `pmtiles extract --bbox=` | mitigate | Bbox unmarshals into `[4]float64` (never raw strings); ValidateRegion range-checks lat [-90,90] / lon [-180,180] and ordering before the entry is ever handed to the builder, mirroring waypoint_cluster.go's checks |
| T-21.5-05 | Denial of Service | malformed / huge config file at startup | accept | Config is admin-supplied and read once at startup; a malformed file yields a parse error surfaced to the operator, an oversized valid file is bounded by Plan 02's sequential build loop + timeout (see Plan 02 threat model). No runtime attacker path to this input. |
| T-21.5-SC | Tampering | package installs | accept | This phase installs no npm/pip/cargo/Go packages (RESEARCH.md Package Legitimacy Audit: N/A) — all mechanisms reuse already-vendored deps; no supply-chain surface added |
</threat_model>
