Extend the shared `WandererFilterChip<T>` with an optional `avatarBuilder` so chips can render a leading icon, and add a `subcategories` l10n key to every ARB locale file. Purpose: D-07 (chip icon support) and the new "Subcategories" section label (UI-SPEC Copywriting; RESEARCH Pitfall 4 — no such key exists yet). The chip extension is backward compatible: existing call sites pass nothing → no avatar rendered.

Output: `WandererFilterChip` with an optional `Widget? Function(T item)? avatarBuilder`, and a `subcategories` ARB key present in all 14 locale files plus regenerated l10n bindings exposing `l10n.subcategories`.
</objective>
