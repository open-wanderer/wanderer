# Phase 45 — UI Design Contract

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Gap between a glyph and its dot badge, ring offsets |
| sm | 8px | Gap between icon and text, chip `spacing`, vertical padding of detail rows |
| md | 16px | Sheet horizontal padding, section gaps, default element spacing |
| lg | 24px | Sheet bottom padding, gap between picker sections |
| xl | 32px | Gap above the primary CTA in the POI sheet |
| 2xl | 48px | Minimum height of tappable rows and of the pill "Retry" button |
| 3xl | 64px | Not used in this phase |

Exceptions:
- 12px: vertical gap between stacked floating controls and the offset above a docked sheet (existing app value: `SizedBox(height: 12)`, `bottom: 164 + 12`). Reused only where a new control joins an existing stack.
- 40px: compact `IconButton` hit size, so the picker button matches the sibling buttons in the existing control pills (eye, expand, mountain, undo, redo). 24px WCAG 2.2 AA target size is met.
- 44px: square hit rectangle used to detect a POI marker tap (`featuresInRect`). Not a layout value.
- 28px and 40px: POI marker diameter on the map (28) and in the sheet header (40). Icon sizes, not spacing.

## Typography

Material text theme in `IBMPlexSans`. Four sizes, two weights.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Caption | 12px | 400 | 1.4 (field labels in the POI sheet, tag keys, attribution links, group "N selected", overlay credit line) |
| Body | 16px | 400 | 1.5 (switch row titles, group titles, detail values) |
| Label | 14px | 600 | 1.4 (section headings "Overlays" and "Points of interest", "Show all tags", "Clear all", "Retry", status pill text). Category chip labels are 14/400 unselected and 14/600 selected, as `WandererFilterChip` already does |
| Heading | 16px | 600 | 1.2 (sheet title "Map layers") |
| Display | 22px | 600 | 1.2 (POI name in the detail sheet header) |

Notes:
- 14px values in tag lists (raw tag value) use 14/400. This reuses the Label size at weight 400; no fifth size is introduced.
- New surfaces set `FontWeight.w600` explicitly. Older sheets use `FontWeight.bold` (700); do not copy that. The bundled SemiBold file is `IBMPlexSans-SemiBold.ttf` (weight 600).
- Secondary text ("fog voice" in DESIGN.md) is `colorScheme.onSurface` at 70% alpha, the same pattern as the selected-location panel on the map screen.
- POI names and OSM tag values are untrusted text: render as plain `Text`/`SelectableText`, `maxLines` 2 with ellipsis for the name, never as HTML or Markdown.

### Map marker palette (the only hues in this phase)

POI hues identify a category on the map; the glyph, not the colour, carries meaning. They are never used for buttons, links, text or backgrounds in the UI chrome. They are the web's seven colour buckets, with four values darkened so the white glyph reaches at least 3:1 (WCAG 1.4.11). The web values (Coral `#FF7F50` 2.5:1, DeepSkyBlue `#00BFFF` 2.1:1, `#e6c100` 1.75:1, HotPink `#FF69B4` 2.65:1) fail.

| Bucket | App fill | Contrast vs white | Web value | Categories |
|--------|----------|-------------------|-----------|------------|
| Food | `#C2410C` | 5.2:1 | Coral | food-drinks, grocery-store, bakery |
| Water and sanitation | `#0369A1` | 5.9:1 | DeepSkyBlue | water, shower, toilets |
| Utility | `#000000` | 21:1 | black | shelter, garage, gas-station, parking |
| Nature and sights | `#008000` | 5.1:1 | Green | attraction, viewpoint, summit, mountain-pass, climbing |
| Lodging | `#8A6A00` | 5.1:1 | `#e6c100` | hotel, campsite, hut |
| Cycling | `#BE185D` | 6.0:1 | HotPink | bicycle-rental, bicycle-shop, bicycle-parking |
| Public transport | `#00008B` | 15.3:1 | DarkBlue | railway-station, subway-stop, tram-stop, bus-stop, ferry |

## Layout and Components

### 1. Layer picker entry button

One shared widget `MapLayerPickerButton`, placed in the host's existing top-right control group. Tooltip and semantic label: "Map layers". Icon `FontAwesomeIcons.layerGroup`, size 18, `IconButton` with `VisualDensity.compact`.

| Host | Placement |
|------|-----------|
| Trail detail (`trail_detail_map_screen.dart`, `_buildMapControls`) | Fourth `IconButton` inside the existing `canvasColor` pill column, after the mountain (elevation) button |
| Main map (`map_screen.dart`) | New flat pill in the `Positioned(top: paddingTop + 76, right: 8)` column, above `WandererMapCompass`. Same construction as `_buildUndoButton`: `canvasColor` fill, radius 24, no shadow. It lives in the `TrailCollectionMap` children, so it hides with the map when the results sheet covers it |
| Route planner (`route_planner_screen.dart`) | Third pill under undo and redo in the same column. The compass `top` offset grows from `kToolbarHeight + 132` to `kToolbarHeight + 188` |

Active indicator: when at least one overlay or POI category is selected and the device is online, draw the 8px dot at the top-right of the glyph (see Color, accent item 4). Hidden while offline, because the layers are hidden.

Offline: the button stays enabled and opens the sheet. A disabled button cannot explain itself. (Deviation from RESEARCH Pitfall 6, which suggests disabling it; on the main map the button is moot anyway because the whole map is replaced by `WandererOfflineState`.)

### 2. Layer picker sheet

`showModalBottomSheet`: `isScrollControlled: true`, top radius 20, `barrierColor: Colors.transparent` so overlays and markers can be seen changing on the map above the sheet, tap outside or drag down dismisses. Height is content-sized, capped at 60% of screen height, content scrolls inside. Padding `fromLTRB(16, 16, 16, 24)` plus `SafeArea`.

Top to bottom:
1. Header row: "Map layers" (Heading) left; close `IconButton` (`FontAwesomeIcons.xmark`, size 16, tooltip = existing `close`) right.
2. Offline notice, only when offline: block with `colorScheme.secondary` fill, radius 8, padding 16, leading `FontAwesomeIcons.linkSlash` size 16, 8px gap, text at 14/400. Copy in the Copywriting Contract. 16px gap above and below.
3. Section "Overlays" (Label). Four `SwitchListTile` rows, min height 56, leading `FaIcon` size 18, title Body:
   - Hiking: `personHiking`
   - Cycling: `personBiking`
   - Mountain biking: `bicycle`
   - Skiing: `personSkiing`
4. Credit line under the rows (Caption, fog voice): "Route overlays by Waymarked Trails". "Waymarked Trails" is an underlined link to `https://www.waymarkedtrails.org`.
5. 24px gap, hairline divider.
6. Section row "Points of interest" (Label) left; "Clear all" `TextButton` (Label) right, shown only when at least one category is selected, disabled while offline. Caption hint under it: "Places appear once you zoom in close."
7. Seven `ExpansionTile` groups in this order: Food, Tourism, Amenity, Hiking, Cycling, Car/Motorcycle, Public transport. Title Body; trailing Caption "N selected" when N > 0, then the chevron. Groups containing a selection start expanded, others collapsed. Expanded body: `WandererFilterChip<String>` with `multiple: true`, `spacing` 8, one 24px category icon as `avatar` (the same bitmap composite as the map marker, so chip and marker match).

Categories offered (26; `barrier` is omitted because it matches nothing today, RESEARCH Pitfall 11 and Open Question 1; `picnic` has no toggle on the web either):

| Group | Categories |
|-------|------------|
| Food | food-drinks, grocery-store, bakery |
| Tourism | campsite, attraction, hotel, hut, viewpoint |
| Amenity | water, shelter, shower, toilets |
| Hiking | mountain-pass, climbing, summit |
| Cycling | bicycle-rental, bicycle-shop, bicycle-parking |
| Car/Motorcycle | garage, gas-station, parking |
| Public transport | railway-station, subway-stop, tram-stop, bus-stop, ferry |

Behaviour:
- Toggling applies immediately and persists. There is no Apply or Cancel button.
- Selection is global: the same state on main map, trail detail and route planner.
- Offline: every switch and chip is disabled but still shows its saved on/off state; "Clear all" is disabled. Disabled controls carry the semantic hint "Unavailable while offline".
- Server without the `/pois` endpoint (HTTP 404): replace the whole POI section (steps 6 and 7) with one Caption line, "This server doesn't support points of interest yet." The overlay section is unaffected.

### 3. Map status pill (loading, hint, unavailable, empty)

A single transient pill per map, centred horizontally, placed below the host's top bar or chip row (executor picks exact offsets per host so it never overlaps the filter/sort chips, search bar or controls column). `canvasColor` fill, radius 24, 1px `colorScheme.outline` border, padding 8 vertical and 16 horizontal, max width screen minus 32. Leading 16px element (spinner or `FaIcon`), 8px gap, Label text. Announced as a live region (`Semantics(liveRegion: true)`).

Priority, highest first; only one shows at a time:

| State | When | Leading | Text | Interactive |
|-------|------|---------|------|-------------|
| Unavailable | Any requested category came back `unavailable` (backoff or upstream failure) | `FontAwesomeIcons.triangleExclamation`, 16, `onSurface` 70% | "Places are temporarily unavailable. Trying again shortly." | Yes: trailing "Retry" `TextButton`, 48px min height; refetches the visible tiles now |
| Loading | A fetch for the settled camera has run longer than 300 ms | `CircularProgressIndicator`, 16px, strokeWidth 2 | "Loading places" | No |
| Zoom hint | At least one category selected, online, zoom below 12 | `FontAwesomeIcons.magnifyingGlassPlus`, 16 | "Zoom in to see places" | No |
| Empty | Fetch finished fresh, zero places in the visible tiles | `FontAwesomeIcons.circleInfo`, 16 | "No places found in this area" | No |

Lifecycle: Unavailable stays until a refetch succeeds; the app also retries once after the server's `retryAfter`. Loading disappears when the fetch settles. Zoom hint disappears at zoom 12. Empty disappears on the next camera move. Stale data (`status: "stale"`) is drawn silently, with no pill. The pill never shows while offline. Not interactive states use `IgnorePointer` so they do not block map gestures.

### 4. Map markers

- Source: `GeoJsonSource('poi')`, one `SymbolStyleLayer('poi', minZoom: 12)`, added last so markers sit above route lines. Overlays sit below the host's trail and route layers (RESEARCH Pattern 6).
- Glyph: the web SVG for each category, composited on a filled circle exactly as the web does (white glyph, 24-unit box), then rasterized once at 96px.
- Composite: 44-unit viewBox, filled circle r=20 centred, 2-unit white outer ring (r=21 stroke 2). The ring keeps black and dark-blue markers visible on the dark map and on raster overlays.
- On-screen size: 28dp diameter including ring from zoom 14; 24dp from zoom 12 to below 14. `icon-size` is tuned on a device because Android scales the bitmap by pixel ratio and iOS does not (RESEARCH Pitfall 14).
- Collisions: `icon-allow-overlap` is false from zoom 12 to below 14 and true from 14, as on the web.
- Tap target: a 44x44 dp rectangle around the touch point (`featuresInRect`). A marker hit opens the POI sheet and consumes the tap: the main map does not drop its location pin and the route planner does not append an anchor.
- Selected feedback: the open sheet is the indicator. A highlight ring on the tapped marker is optional (executor discretion, only if it needs no extra layer API).
- Known limitation: native map symbols are not reachable by screen reader. v1 does not add a list alternative.

### 5. POI detail sheet

`showModalBottomSheet` (`isScrollControlled: true`, top radius 20, transparent barrier so the tapped marker stays visible, content scrolls, max height 70%). The sheet is built from the cached OSM element, so it needs no loading state of its own. Fetch states are covered by the status pill.

Top to bottom:
1. Header (padding 16): 40px category marker (same composite) and a text column: name (Display, max 2 lines, ellipsis) over the category label (Caption, fog voice); close `IconButton` right. Unnamed POI: the category label becomes the title (Display) and the caption line is omitted.
2. Hairline divider.
3. Curated rows. Shown only when the tag exists, in this order. Row layout: 24px leading `FaIcon` size 16 in fog voice, 16px gap, then a column of label (Caption, fog voice) over value (Body). Vertical padding 8, rows with an action have 48px minimum height and an `InkWell` over the whole row.

| Row | Label | Tags read | Icon | Value and action |
|-----|-------|-----------|------|------------------|
| Address | Address | `addr:street`, `addr:housenumber`, `addr:postcode`, `addr:city` | `locationDot` | Two lines: "street number" then "postcode city". Not tappable |
| Opening hours | Opening hours | `opening_hours` | `clock` | Raw string, split at `;` into one line per rule. No parsing in v1 |
| Website | Website | `website`, else `contact:website` | `globe` | Host only, underlined. Tap opens `http`/`https` only (bare hosts get `https://`); any other scheme renders as plain text with no action |
| Phone | Phone | `phone`, else `contact:phone` | `phone` | Number as written, underlined. Tap opens `tel:` built from digits and a leading `+` only |
| Wheelchair access | Wheelchair access | `wheelchair` | `wheelchair` | "Yes", "Limited" or "No"; any other value hides the row |
| Elevation | Elevation | `ele` | `mountain` | `formatElevation` in the user's unit; shown for summit and mountain-pass |
| Drinking water | Drinking water | `drinking_water` | `faucetDrip` | "Yes" or "No"; any other value hides the row |
| Fee | Fee | `fee` | `moneyBill` | "Yes" or "No"; any other value hides the row |

4. "Show all tags" disclosure: full-width row, 48px min height, Label text, trailing Caption count and chevron (`chevronDown`, rotates 180 degrees when open). Open state reads "Hide all tags". Expanded body lists every tag sorted by key: two columns, key (Caption, fog voice, 40% width) and value (14/400, `SelectableText`, wraps), 8px row gap. Hidden when the element has no tags.
5. Stale notice, only when the tile's status was `stale`: Caption line "Place data last refreshed on {date}." (`intl` `yMMMd`).
6. Route planner only: sticky footer with a full-width `WandererButton(primary: true)` "Add to route", leading `FontAwesomeIcons.plus`. It calls `appendAnchor(Geographic(lat, lon))`, closes the sheet and shows the toast "Added to route". No confirmation dialog because the planner's Undo reverses it. On main map and trail detail the footer is absent. This item is the stretch goal; the sheet takes an optional `onUseAsAnchor` callback and renders the footer only when it is set.

If no curated row applies, the body shows "No further details for this place." (Body, fog voice) above the disclosure.

### 6. Overlay and POI attribution

- `WandererAttribution` stays collapsed by default (existing app behaviour) and accepts an `extra` list of HTML strings from the selection provider. Entries, only while online and the layer class is active:
  - Any overlay on: `<a href="https://www.waymarkedtrails.org">Waymarked Trails</a>` and `<a href="https://www.openstreetmap.org/copyright">OpenStreetMap contributors</a>`.
  - Any POI category on: `<a href="https://www.openstreetmap.org/copyright">OpenStreetMap contributors</a>` (deduplicated).
- Because the info button hides the text until tapped, the picker sheet carries the always-visible credit line (section 2, step 4) so the Waymarked Trails credit is on screen at the moment the overlay is enabled.
- Attribution refreshes when the selection changes, not only when the style object changes (RESEARCH Pitfall 5).

### 7. Motion

- No new animation on the map: layers appear and disappear without a fade.
- Picker chevron rotation, status pill fade and sheet expand/collapse follow the platform defaults. When `MediaQuery.disableAnimationsOf(context)` is true (precedent: `home_screen.dart:79`) the chevron and pill switch instantly.
- Hover and press states: Material defaults; no custom movement.
