<objective>
Deliver REGN-01: a bundled `assets/map/regions.json` app asset plus a typed `@freezed` parse model (`RegionManifest` / `RegionManifestEntry`) that reads it field-by-field. Ship 4 real regions with real bbox coordinates and real (relative) tile-endpoint URLs — not placeholder data (D-03/D-04).

Purpose: This manifest is the seed source every later v1.6 phase reads from — Phase 23's `TileRepositoryManager` will map each entry into an ObjectBox `Region` row (Plan 02 defines that entity; Phase 23 wires the seeding). Getting the parse model's shape and the URL/size field semantics right here avoids a schema refactor once real downloads exist.

Output: One bundled JSON asset, one freezed parse model (+ generated `.freezed.dart`/`.g.dart`), and a parse test that doubles as the CI guard against a malformed manifest.
</objective>
