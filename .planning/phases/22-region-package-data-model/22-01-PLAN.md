<objective>
Build the full app-side schema for v1.6's offline region tile repository: the typed parse model for Phase 21.5's `GET /api/v1/regions` catalog response, the explicit-`.code` status enums, and the two ObjectBox entities (`RegionEntity`, `DownloadedTilePackageEntity`). This is the foundation every later v1.6 phase reads from.

Purpose: Get the status-enum persistence contract (explicit stable int constants, never `.index`) and the upsert-safe entity shape right before any real downloads exist on-device — a data-corruption class of bug that is expensive to retrofit once real rows exist (REGN-02).

Output: `region_status.dart`, `region_catalog_entry.dart` (+ generated), `downloaded_tile_package_entity.dart`, `region_entity.dart` (+ regenerated `objectbox.g.dart`/`objectbox-model.json`), and unit tests. Purely additive — nothing reads these entities yet; the app builds and runs unchanged.
</objective>
