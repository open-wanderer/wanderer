<objective>
Deliver REGN-02 and REGN-03: two ObjectBox entities. `RegionEntity` persists every manifest field plus a computed `RegionStatus`, and `DownloadedTilePackageEntity` tracks the vector and DEM tile packages for a region independently. Both entities persist their status via explicit stable int `.code` constants — never `Enum.values[index]` — the exact anti-pattern REGN-02 forbids (D-01/D-02).

Purpose: This is the on-device schema every later v1.6 phase writes to and reads from. The `.code` persistence contract and the computed-status design (D-07) are locked here so that when Phase 23's `TileRepositoryManager` starts mutating package rows, Region status can never drift out of sync and no future enum reordering silently reinterprets stored values.

Output: Two entity files (+ regenerated `objectbox.g.dart` / `objectbox-model.json`) and a unit test suite. The app still builds and runs unchanged — nothing reads these entities yet (Phase 22 success criterion 4). Because 22-02 is the last plan in the phase (wave 2), it carries the Task 3 gate that makes success criterion 4 machine-verifiable across the whole phase (it greps for all three new files including Plan 01's `region_manifest.dart`).
</objective>
