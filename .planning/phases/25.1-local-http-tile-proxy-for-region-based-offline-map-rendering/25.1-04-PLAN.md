<objective>
Unify BOTH `TrailMap` and `navigation_screen` on the loopback tile proxy (D-01): start the `TileProxyServer` in `main.dart`, then rewrite each screen's `_composeStyle` to bake the single static loopback XYZ source (via `rewriteStyleForProxy`) instead of enumerating per-viewport `.pmtiles` cell paths — and delete the entire incremental source/layer reconcile machinery from both files. This is the structural fix for the Phase 25 UAT Test 4 reentrancy race: with no reconcile call there is no race (diagnosed in `.planning/debug/navigation-screen-region-swap-broken.md`), and unifying both screens removes the `_sourceFromJson`/`_layerFromJson` duplication D-01 targets.

GATE: This plan proceeds only after Plan 03's `checkpoint:decision` returns "proceed". Read `25.1-03-SUMMARY.md` first — its recorded test-case-(d) result (does a mid-session region download appear without a remount?) determines the mid-session-refresh handling below. Per D-04, if the spike did not confirm offline loopback loading, this plan does NOT run — the phase reassessed with the user instead.

Purpose: PROXY-01 — both screens serve offline vector/DEM tiles through one static XYZ source backed by the loopback server, replacing `_reconcileRegionComposition`/`_addRegionComposition` entirely.

Output: `main.dart` starts the server + overrides the base-URL provider; `trail_map.dart` and `navigation_screen.dart` compose via `rewriteStyleForProxy` with all tracking-set/reconcile/`_sourceFromJson`/`_layerFromJson`/`_seedRegionTracking` code removed.
</objective>
