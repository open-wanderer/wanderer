<locked_decisions>
Two ambiguities flagged in RESEARCH/PATTERNS are locked here:
- **Switch polarity (D-10):** Follow the UI-SPEC interaction contract (06-UI-SPEC.md line 122, the authoritative visual spec): `value: settings?.unit == 'imperial'` → imperial is the on-position, metric the off-position. SwitchListTile `title` uses `l10n.imperial`. A `Text(l10n.units)` section label sits above the switch.
- **RadioGroup type:** Use `RadioGroup<Language>` (not `<String>`) — the model exposes a `Language` enum, and using it avoids string-matching bugs (RESEARCH Open Q2 recommendation). Map each `Language` value to its native-name label via a hardcoded `const Map<Language, String>`.
</locked_decisions>
