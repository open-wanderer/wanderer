# Phase 5 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

> **Scope note:** This is a Flutter (Material) phase, not React/Next/Vite. The shadcn gate does not apply. The single UI deliverable (OFFLINE-04) is a conditional trailing `FaIcon(FontAwesomeIcons.wifiSlash)` inside the existing `_buildBanner` widget in `app/lib/routes/navigation_screen.dart`, shown only when `isOffline == true`. No new screens, no new navigation flows, no new layout layers, no new colors, fonts, or spacing tokens are introduced. All values below are inherited from the existing Material `Theme` and the established `NavigationScreen` patterns; the contract documents them so the executor reproduces them exactly. (Source: CONTEXT.md D-04, D-05; existing code `navigation_screen.dart:284-355`.)

## Spacing Scale

Declared values (must be multiples of 4). This phase introduces NO new spacing tokens — only the tokens actively used by the new change are listed below.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon padding for the trailing offline indicator (mirrors existing fine-grained spacing) |
| sm | 8px | Leading gap before the trailing wifi-off icon (`SizedBox(width: 8)`), reusing the existing 8px maneuver-icon gap (`EdgeInsets.only(right: 8.0)`) |

> **Pre-existing banner padding (not a new token):** The existing `_buildBanner` widget uses `EdgeInsets.symmetric(horizontal: 16.0, vertical: 12.0)`. This phase does not change it. The `vertical: 12.0` value is an inherited, pre-existing layout value — it is NOT introduced or modified by this phase and is therefore not declared as a spacing token here.

**Exceptions:** The trailing offline icon introduces NO new spacing token. It must use an 8px leading gap (`SizedBox(width: 8)` or `EdgeInsets.only(left: 8.0)`) to mirror the existing 8px maneuver-icon gap. The banner's own padding is unchanged.

## Color

All colors inherited from the existing Material `colorScheme`. The banner background is `colorScheme.surface`; the maneuver icon and instruction text use `colorScheme.onSurface`. No new color is introduced.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `colorScheme.surface` | Banner card background — existing |
| Secondary (30%) | `colorScheme.onSurface` | Maneuver icon, instruction/distance text — existing |
| Accent (10%) | `colorScheme.onSurface` (NOT a new accent) | Offline `wifiSlash` icon tint |
| Destructive | not used in this phase | — |

**Accent reserved for:** The offline `FaIcon(FontAwesomeIcons.wifiSlash)` MUST be tinted with `Theme.of(context).colorScheme.onSurface` — the identical tint used by the existing maneuver icon and FaIcons elsewhere in `NavigationScreen` (`xmark`, `chartSimple`, `locationCrosshairs`). Do NOT introduce a red/error or brand-accent color; the indicator is informational, not an error state, and consistency with the existing banner icons is the contract. Icon size MUST be `20`–`24` (the existing maneuver icon is `size: 24`; a slightly smaller `20` is acceptable for a secondary trailing indicator). (Source: CONTEXT.md D-05; existing code `navigation_screen.dart:326-330`.)

## Copywriting Contract

This phase ships no new strings, CTAs, or dialogs. The offline state is communicated purely by the icon. Existing localized strings and the existing error toast are reused unchanged.

| Element | Copy |
|---------|------|
| Primary CTA | None — no new button or CTA in this phase |
| Empty state heading | None — no new empty state (banner already handles empty maneuvers via `SizedBox.shrink()`) |
| Empty state body | None |
| Error state | Reuse the EXISTING error toast shown today on network failure. When both the online fetch AND the cache read fail, fall through to the same toast — no new error copy. (Source: CONTEXT.md D-11.) |
| Destructive confirmation | None — this phase has no destructive actions. Cache re-write is silent/best-effort and fire-and-forget; cache fallback is automatic. (Source: CONTEXT.md D-06, D-12.) |

> **Offline indicator semantics:** The `wifiSlash` icon is the sole signal that navigation is running from cached instructions. No accompanying text label, tooltip, banner copy, or "cached N days ago" string is permitted (explicitly Out-of-Scope per REQUIREMENTS.md and STATE.md Deferred Items). (Source: CONTEXT.md D-04, D-05.)

## Interaction & Placement Contract (Flutter-specific)

| Item | Contract |
|------|----------|
| Trigger | `NavigationScreen` gains an `isOffline: bool` constructor parameter. Icon renders only when `widget.isOffline == true`; otherwise nothing renders (`if (widget.isOffline) ...` — no placeholder `SizedBox`). (CONTEXT.md D-01, D-04.) |
| Location | Inside the EXISTING `_buildBanner` / `_buildActiveBannerContent` `Row`, at the trailing edge after the `Expanded` instruction column. No new `Stack`, `Positioned`, `AppBar` action, or overlay layer. (CONTEXT.md D-04.) |
| Widget | `FaIcon(FontAwesomeIcons.wifiSlash)` — matches existing FaIcon usage in `NavigationScreen`. `wifiSlash` is available in font_awesome_flutter 11.0.0. (CONTEXT.md D-05.) |
| Tint | `Theme.of(context).colorScheme.onSurface` (consistent with existing banner icons). |
| Size | `20`–`24` (existing maneuver icon is `24`). |
| Leading gap | `SizedBox(width: 8)` before the icon to match the existing 8px icon gap. |
| Non-obstruction | The instruction `Text` stays inside `Expanded` so the trailing icon never truncates or overlaps the maneuver text. The icon occupies fixed trailing space only. (CONTEXT.md "specifics".) |
| Completion banner | The offline icon also applies to the active banner; placement in the completion (`_buildArrived`) banner is at executor discretion but must follow the same tint/size/gap rules if shown. |
