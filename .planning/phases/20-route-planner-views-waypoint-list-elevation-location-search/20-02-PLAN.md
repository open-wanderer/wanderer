<objective>
Build the dedicated location-only search screen (PLANUI-03, D-14/D-15) as a
near-verbatim mirror of `GlobalSearchScreen`, minus the category-chip row and
every non-location result branch, and register it as a go_router route so the
Route Planner can push it and await a `LocationSearchResult`. On selection the
screen pops back to its caller (never `context.go('/map')`) so the planner owns
the camera animation.

This plan is independent of the data layer (Plan 01) — it reuses the existing
`globalSearchProvider` and `LocationSearchResult` model unchanged — so it runs
in Wave 1 in parallel with Plan 01.

Purpose: Give the planner a search-to-focus entry point that returns a result
to the already-open planner route rather than navigating away.
Output: A new `LocationSearchScreen`, plus a `/location-search` route.
</objective>
