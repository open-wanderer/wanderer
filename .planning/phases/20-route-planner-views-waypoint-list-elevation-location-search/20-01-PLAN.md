  <action>
    Add two public void mutators to the `RouteAnchors` notifier class, each following the established shape: call `_pushUndo()` FIRST, then rebuild `anchors`/`segments` via `state.copyWith(...)`, then conditionally dispatch Valhalla resolves via `_resolveSegment(before, after, a, b).ignore()` only when `state.autoRoutingEnabled`.

    `deleteAnchor(String anchorId)` implements RESEARCH.md Pattern 2: compute the surviving `anchors` list (filter out `anchorId`); find the `before` segment (the one whose `afterAnchorId == anchorId`) and the `after` segment (whose `beforeAnchorId == anchorId`) using `firstWhere`/`firstWhereOrNull` semantics (null when the deleted anchor was first or last); build the new `segments` list = all segments not touching `anchorId`, PLUS (only when both `before` and `after` exist) one new `RouteSegment(beforeAnchorId: before.beforeAnchorId, afterAnchorId: after.afterAnchorId, polyline: [predecessor.point, successor.point], state: SegmentState.straight)` where predecessor/successor are looked up from the surviving `anchors` by id. Apply via a single `state = state.copyWith(anchors: ..., segments: ...)`. Finally, when both `before` and `after` existed AND `state.autoRoutingEnabled`, call `_resolveSegment(before.beforeAnchorId, after.afterAnchorId, predecessor, successor).ignore()`. Use `collection`'s `firstWhereOrNull` (already used elsewhere in the app) or an equivalent null-safe lookup — do not let `firstWhere` throw when there is no before/after segment.

    `reorderAnchors(List<String> newOrder)` implements RESEARCH.md Pattern 3 (adjacency diff): build `anchorsById` map; map `newOrder` ids to the reordered `List<RouteAnchor>`; build `oldByKey = {segmentKey(s.beforeAnchorId, s.afterAnchorId): s for s in state.segments}`; walk consecutive pairs of the reordered list — for each pair `(a, b)` compute `segmentKey(a.id, b.id)`; if `oldByKey` has that key, reuse the existing `RouteSegment` verbatim (preserves its resolved polyline/state); otherwise create a fresh `RouteSegment(beforeAnchorId: a.id, afterAnchorId: b.id, polyline: [a.point, b.point], state: SegmentState.straight)` and, when `state.autoRoutingEnabled`, queue it for a post-`copyWith` `_resolveSegment(a.id, b.id, a, b).ignore()`. Apply `state = state.copyWith(anchors: reordered, segments: newSegments)` before dispatching any queued resolves.
