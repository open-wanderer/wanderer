<objective>
Create `db/routes/federation_admin.go` with the discovery handler and the shared helpers
that the other five handlers (Plans 02 and 03) will reuse. `POST /federation/discover` is
the required first step of the connect flow: it fetches the remote instance's NodeInfo,
verifies it is a Wanderer instance, runs the SAFE-05 self-follow and "already connected"
guards, refreshes the cached actor (bypassing the 2-hour cache per D-03), and returns a
preview card payload.

Purpose: Satisfy DISC-01 (preview card), DISC-02 (clear errors), SAFE-05 (self-follow
guard), and SAFE-06 (10-second SSRF-safe client). This is the heaviest handler in the
phase; isolating it keeps each plan within context budget.

Output: `db/routes/federation_admin.go` (new) containing `FederationDiscover` plus shared
helpers `newDiscoveryClient`, `fetchNodeInfo21URL`, `pickNodeInfo21Href`, and a local
instance actor lookup helper; plus `db/routes/federation_admin_test.go` with unit tests
for the pure helpers. Route registration in `db/main.go` happens in Plan 03 (all six
routes registered together to keep the shared `main.go` edit in one wave).
</objective>
