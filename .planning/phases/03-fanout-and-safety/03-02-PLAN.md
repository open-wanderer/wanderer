|----------|-------------|
| remote peer → instance inbox → processCreateOrUpdate* | untrusted Create/Update activities cross here; replayed Creates must not create duplicate local records |
| local content hook → outgoing fanout | private content (comment on private trail) must never be emitted to any follower |
