<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| remote peer → instance inbox → ProcessDeleteActivity | untrusted Delete activities cross here; a Delete must only be applied if the signed sender owns the target record |
| remote peer → instance inbox → ProcessCreateOrUpdateActivity | untrusted Create/Update activities cross here; already authenticated by HTTP signature (Phase 2, unchanged), dedup-guarded in Plan 02 |
| local content hook → outgoing delete fanout | a public record delete must reach instance followers so they drop their cached copy |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-06 | Tampering | processDeleteTrailActivity applying a Delete for a trail the remote actor does not own | mitigate | SAFE-02: `trail.GetString("author") != actor.Id` guard returns `fmt.Errorf` before `util.DeleteFromFeed`/`app.Delete`; propagates as 400 via InstanceInboxHandler (Task 1) |
| T-03-07 | Spoofing | a remote actor forging a Delete to remove another instance's trail | mitigate | sender identity is established by HTTP signature verification in InstanceInboxHandler (Phase 2, unchanged); SAFE-02 ownership check then rejects any actor that is not the record author |
| T-03-08 | Denial of Service | malicious Delete storm against the instance inbox | mitigate | every Delete is signature-authenticated (Phase 2) and authorized (SAFE-02); non-matching actors are dropped with a 400 before any DB delete, so the storm cannot remove content |
| T-03-09 | Information Disclosure | private (non-public) trail/list delete leaking to instance followers | accept | existing `if !r.GetBool("public") { return nil }` gate in CreateTrailDeleteActivity (line 17) / CreateListDeleteActivity, and the parent-trail public state for summit_log/comment, already gate the public path; instance fanout is appended only after those gates — no new disclosure surface |
| T-03-SC | Tampering | npm/pip/cargo installs | accept | no package installs in this plan — RESEARCH.md "Package Legitimacy Audit: not applicable" |
</threat_model>
