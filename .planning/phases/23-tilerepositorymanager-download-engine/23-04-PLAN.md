<objective>
Build `TileRepositoryManager` — the first resumable download primitive in this codebase. It downloads a region's pre-built vector (and, independently, DEM) `.pmtiles` archive from Phase 21.5's catalog endpoint, resuming an interrupted transfer from a `.part` byte offset via HTTP Range + `FileAccessMode.append` (never from byte 0), refusing to start when disk space is tight, validating the completed archive with the `pmtiles` package's own header parser before promoting `.part` to the final path, and treating app backgrounding as a deliberate pause rather than a frozen socket. It mirrors `trail_download_service.dart`'s construction-injection + `CancelToken` shape but adds the region-scale concerns the trail-cell code never needed.

Purpose: Delivers the phase's download-lifecycle core (TILE-01 start/pause/resume, TILE-02 resume, TILE-03 disk check, TILE-04 backgrounding, DEM-01/02 independent DEM). Deletion and the bbox query and the Riverpod wiring land in Plan 05.
Output: `tile_repository_manager.dart` with the download primitive, disk check, validation, batched status writes, public start/pause/resume for vector and DEM, and the `AppLifecycleListener`-driven backgrounding pause; a unit test for the pure `resumePlanFor` helper.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Catalog-declared size/url → local write | `vectorSize`/`vectorUrl` from the fetched catalog drive disk-check and availability |
| Downloaded bytes → offline map data | A truncated/corrupt archive would silently break offline rendering |
| OS lifecycle signal → in-flight socket | Backgrounding must not leave a dead transfer |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-23-01 | Tampering | region id → file path / request path | mitigate | `assertValidRegionId` before path/URL construction; request path built from validated id, never from the catalog url string |
| T-23-02 | Tampering / DoS | downloaded `.part` archive | mitigate | `PmTilesArchive.fromFile` validation gates the `.part` → final rename; a corrupt file is deleted and the package marked `error`, never promoted |
| T-23-03 | Denial of Service | oversized/mismatched declared size | mitigate | `hasEnoughSpace` re-checked before each file with a 1.75x margin; refuse with `error` state before any write |
| T-23-06 | Denial of Service | resumed download re-requesting stale offset | accept | The Range offset is computed from the app's own local `.part` file length, never server-supplied — not attacker-controllable |
</threat_model>
