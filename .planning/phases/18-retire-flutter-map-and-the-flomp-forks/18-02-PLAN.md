<objective>
With every source-level importer severed by Plan 01, remove the six now-unused map
packages and the two `flomp/*` git overrides from `pubspec.yaml`, pin `maplibre`
to an exact version, resolve the smaller dependency graph, and prove the removal

with no arbitrary GitHub `ref: main` in its trust boundary.

Purpose: Deliver CLEAN-01 (four flutter_map-family packages gone), CLEAN-02
(vector_map_tiles / vector_tile_renderer gone, flomp overrides gone), and CLEAN-03
(maplibre pinned against its pre-1.0 breaking-change cadence). The whole-package
analyze is the gate that catches the `tool/` pitfall a `lib/`-scoped analyze would
silently miss.

Output: A resolved dependency tree free of the six packages, `maplibre` pinned exact,
and a clean whole-package analyze + green test suite.
</objective>
