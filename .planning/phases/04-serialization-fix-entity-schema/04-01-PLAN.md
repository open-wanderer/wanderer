<objective>
Fix the confirmed `NavigateResponse.toJson()` serialization bug that blocks ObjectBox caching, then prove the fix with a roundtrip unit test group.

The generated `_$NavigateResponseToJson` currently emits `'maneuvers': instance.maneuvers` (navigate_response.g.dart line 41) — a raw list of `NavigateManeuver` objects that `jsonEncode` cannot serialize, so it throws at runtime. Adding `@JsonSerializable(explicitToJson: true)` to `NavigateResponse` makes codegen emit `instance.maneuvers.map((e) => e.toJson()).toList()`.

Purpose: This is the BLOCKING prerequisite for all Phase 5 ObjectBox caching. Without correct serialization, navigation instructions cannot be persisted or read back.
Output: Corrected `navigate_response.dart` annotation, regenerated `navigate_response.g.dart`, and a new roundtrip test group proving encode→decode→reconstruct works for full, empty, and minimal-field cases.
</objective>
