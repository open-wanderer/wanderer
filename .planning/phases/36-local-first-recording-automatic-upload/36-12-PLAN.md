<objective>
Close the second half of UAT gap 2 (major): point the own-trails list at the detail route
36-11-PLAN created, and stop every remaining `/trail/${trail.id}/...` push from emitting an
unroutable path for a trail with no server id.

`_onTrailSelect` (`profile_trail_screen.dart:53-62`) short-circuits every unsynced trail to
`/trail/create/edit`. `trail_panel.dart` pushes `/trail/${trail.id}/map` at three places
(:300 inline map tap, :324 expand button, :332 elevation profile tap), each of which
becomes `/trail//map` for an unsynced trail. And `TrailDetailMapScreen` can only load a
trail by server id, so the `map` sub-route under `/trail/local/:localId` could not be
declared until it accepts a `localId`.

Purpose: without this plan 36-11's detail screen has no caller and the user's reported
behaviour is unchanged. With it, "tapping a not synced trail opens this trail like any
other trail in the trail detail screen" is true.

Output: the divert is gone, replaced by the shared `trailDetailLocation`; the three panel
pushes go through `trailMapLocation`; the local map route exists; and a widget test pumps
the real list and asserts the real pushed location, so the divert cannot return unnoticed.
</objective>
