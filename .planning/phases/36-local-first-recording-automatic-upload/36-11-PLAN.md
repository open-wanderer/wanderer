<objective>
Close the first half of UAT gap 2 (major): make an unsynced trail *addressable* and
*openable* in the ordinary trail detail screen.

`_onTrailSelect` diverts unsynced trails to `/trail/create/edit` because D-06 blanks a
local-sentinel id at the model boundary (`trail_entity.dart:292`), so `/trail/${trail.id}`
emits `/trail/`, which go_router canonicalizes to `/trail` — a path with no GoRoute.
Deleting the divert alone therefore produces a no-route error page, not the detail screen.
`trailProvider` cannot load a local trail either: its ObjectBox fallback filters on
`savedByUserIds`, which local captures never set and — per D-10 — must never set.

This plan builds the missing machinery: an owner-scoped local-id read, a synchronous
provider over it, one shared route-location helper, a `/trail/local/:localId` route, and a
detail screen that renders a trail with no server id while hiding every affordance that
needs one. 36-12-PLAN then removes the divert, points the list at it, and retargets the
remaining map pushes.

Purpose: REC-02/REC-05 promise the hiker can open and review an unsynced trail like any
other. Today the detail screen is unreachable for one, which also makes the whole of
D-14/D-17's dropdown gating unreachable and blocks UAT Test 3 outright.

Output: `/trail/local/<localId>` resolves to a working detail screen with Download and Like
hidden and Edit offered in place of Navigate.
</objective>
