<objective>
Close CR-01: the phase's primary flow — record, save, fix a typo — fails permanently with a
generic error. `_finishLocalSave` snapshots `trail` while the row's id is still a local sentinel
(so `TrailEntity.toModel()` blanks it to `''`), nothing re-reads it after the drain retires the
row, and there are no ObjectBox `Query.watch()` streams anywhere in this app. Every subsequent
save therefore routes to `LocalSaveMode.networkUpdate`, fails `_saveViaNetwork`'s
`trailHasServerId` guard, and shows `error_saving_trail` — the same string a 500, a timeout and
a malformed payload produce. `_hasUnsavedChanges` stays true, so backing out prompts "discard
changes?" and the edit is destroyed.

The prior fix pass shipped only the refusal half of the previous review's stated minimum
("refuse the save **and tell the user to re-open the trail**"). This plan ships the other half
and the id carry-forward that makes the refusal unnecessary in the common case.

Also closes WR-01, which the review identifies as one of the two doors into CR-01:
`localTrailProvider(localId)` is never invalidated when the drain retires the row, so a hiker
sitting on `/trail/local/<localId>` keeps rendering a row that no longer exists, with a live
Edit button that walks straight into the dead end.

Purpose: this is the single most common post-record action in the whole phase, and it is
currently 100% reproducible broken.
Output: a server id that survives retirement, an actionable refusal message, and a detail
screen that follows the trail to its new home.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Account A's drain → account B's session | `TrailSync` is deliberately excluded from `accountScopedProviders`, so anything it memoizes outlives an account switch |
| Retired server id → `POST /trail/form/{id}` | The memoized id becomes the target of an authenticated write issued from a screen the hiker may have had open across a switch |
| Retired server id → `context.pushReplacement('/trail/<id>')` | A route location built from a value that originated in a server response body |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-36-16-01 | Elevation of Privilege | `TrailSync._retiredServerIds` | mitigate | Each entry stores the owning `accountId`; `serverIdForRetired` re-reads `currentAccountId(store)` at point of use and returns null on mismatch, logging the refusal |
| T-36-16-02 | Information Disclosure | `serverIdForRetired` returning another account's trail id | mitigate | Same account-match check; a null account also returns null (never an unscoped read), matching `current_account.dart`'s documented contract |
| T-36-16-03 | Denial of Service | unbounded growth of the memo on a `keepAlive` notifier | mitigate | `_rememberRetiredServerId` evicts oldest-first above 64 entries |
