```dart

    required String id,
    required String name,

    required List<NavigateManeuver> maneuvers,
    required List<List<double>> shape,

  factory NavigateResponse.fromJson(Map<String, dynamic> json) => _$NavigateResponseFromJson(json);

```

**Field-naming convention** — `navigate_response.dart:13` shows the snake_case-via-JsonKey idiom (`@JsonKey(name: 'begin_shape_index') required int beginShapeIndex`). Pick ONE convention for all four new models (Research Open Q1).

Add `CategoryTranslation` nested freezed type (flat, `String? name`, `String? short_name`) plus `short_name`, `icon`, `Map<String, CategoryTranslation>? translations` to `Category`. Add `displayName(Locale?)` extension (see Shared Patterns / Locale).

## Shared Patterns

### Nested freezed JSON serialization
**Source:** `app/lib/models/navigate_response.dart:24-29`
**Apply to:** `category.dart`, `subcategory.dart`, `CategoryTranslation` (any model with `Map<String, CategoryTranslation>`)
```dart
@JsonSerializable(explicitToJson: true)   // ON the factory constructor line, NOT above @freezed
const factory NavigateResponse({ ... }) = _NavigateResponse;
```
Misplacement silently breaks nested serialization (Research Pitfall 3).

### ObjectBox JSON-blob storage
**Source:** `app/lib/entities/settings_entity.dart:1, 50-54 (write), 84-92 (read)`
**Apply to:** `CategoryEntity.translationsJson`, `SubcategoryEntity.translationsJson`
`jsonEncode(map.map((k,v) => MapEntry(k, v.toJson())))` on write; `jsonDecode` + `.map(...fromJson...)` on read. Requires `import 'dart:convert';`.

### ObjectBox indexed-unique id entity
**Source:** `app/lib/entities/category_entity.dart:6-14`
**Apply to:** `SubcategoryEntity` (+ extra `@Index() String category` per CAT-03)
```dart
@Id() int obxId = 0;
@Index() @Unique(onConflict: ConflictStrategy.replace) String id;
```

### keepAlive ObjectBox-read provider
**Source:** `app/lib/provider/settings_provider.dart:10-19, 22-30`
**Apply to:** `subcategory_provider.dart`, both preference providers
```dart
@Riverpod(keepAlive: true)
// build() reads box.getAll(); mutations put + ref.invalidateSelf()
```

### Anonymous auth gate
**Source:** `app/lib/provider/list/list_search_provider.dart:61` (`ref.read(authProvider).value`)
**Apply to:** both preference providers — return `[]` when `user == null` (D-07).

### List API response parsing
**Source:** `app/lib/models/list_result.dart` + `category_provider.dart:21-26`
**Apply to:** `/category`, `/subcategory` ONLY (`ListResult.fromJson(...).items`). Preference endpoints use bare-array parse instead (Pitfall 2).

### Locale-aware display name
**Source:** `app/lib/provider/local_settings_provider.dart:46-49` (`locale(Ref)` returns `Locale?`)
**Apply to:** `Category`/`Subcategory` `displayName` extension (CAT-01):
```dart
String displayName(Locale? locale) =>
    translations?[locale?.languageCode]?.name ?? translations?['en']?.name ?? name;
```

cd app && dart run build_runner build --delete-conflicting-outputs
