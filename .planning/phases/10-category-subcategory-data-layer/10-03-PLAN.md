## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-05 | Elevation of Privilege | Client crafting a PUT body with an arbitrary `user` id to write another user's preference | mitigate | PUT body restricted to `{category, visible}` / `{subcategory, visible}`; server ignores any client `user` and injects `event.locals.user.id` (verified RESEARCH Security Domain). Gate asserts `grep "'user':"` returns 0 |

| T-10-07 | Tampering/DoS | Malformed preference JSON array | mitigate | Nullable id/visible/priority tolerate missing fields; fetch wrapped in try/catch like CategoryNotifier |
| T-10-SC | Tampering | npm/pip/cargo installs | accept | No package installs — only codegen via existing build_runner (RESEARCH Package Legitimacy Audit: not applicable) |
