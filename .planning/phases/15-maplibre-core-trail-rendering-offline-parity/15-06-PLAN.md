## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| trail cell paths + cache root -> constructed file:// / pmtiles:// URLs | Local paths become style source/glyph/sprite URLs read by native GL |
| downloaded .pmtiles + cached glyphs/sprite -> renderer | On-device artifacts are read with no network |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-06-01 | Tampering | file:// / pmtiles:// paths built by the rewriter | mitigate | `rewriteStyleForOffline` roots every path at the app-docs cache/library root, rejects `..` and foreign schemes, and emits only `pmtiles://file://` + `file://` — enforced by `offline_style_rewriter_test.dart` (RESEARCH Security V5/V12) |
| T-15-06-02 | Info disclosure | reading local files outside the sandbox | mitigate | Only `getApplicationDocumentsDirectory()`-rooted paths are accepted; no external absolute path enters the style |
| T-15-06-03 | DoS | N-source x N-layer duplication for a huge multi-cell trail | accept | Bounded by realistic cell count (0.5deg grid -> ~1-4 cells per trail); `is_large` full-polyline trails are deferred (FUT-01) |
| T-15-06-SC | Tampering | package installs | accept | No new packages; `pmtiles` provider file is DELETED (OFFL-06), not added (RESEARCH Package Legitimacy Audit) |
</threat_model>
