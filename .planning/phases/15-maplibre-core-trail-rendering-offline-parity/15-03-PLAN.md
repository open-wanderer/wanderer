<objective>
Build the one shared app-wide glyph/sprite cache (GLYPH-04, D-08): a `@Riverpod(keepAlive: true)` provider that, on first read, downloads the complete glyph set (all 4 fontstacks × the full range set) plus both light and dark sprite sheets into the app documents directory, idempotently (skip-if-present), and wire the trail-download trigger (D-10) so downloading a trail warms the cache even before any map open. This gives OFFL-01 (second download reuses the cache) for free by construction.

Path-safety is the load-bearing security control (RESEARCH § Security Domain V5/V12): cache filenames must derive only from the 4 whitelisted fontstacks + numeric ranges, rejecting any `..` traversal, with every path rooted at `getApplicationDocumentsDirectory()`.

Purpose: A downloaded trail must render labels + icons offline (OFFL-04, delivered in 15-06); that requires the glyphs/sprite to already be on disk, cached once and shared across all trails.
Output: `map_cache_path.dart` (+ test), `glyph_sprite_cache_paths.dart`, `glyph_sprite_cache_provider.dart`, and the D-10 download trigger.
</objective>
