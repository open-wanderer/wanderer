<objective>
Close CR-01's UI half and CR-03's UI half with one predicate (D-04 / D-12 / D-13 / D-14), and add
the fixture that would have caught this entire phase (WR-12 / D-17).

Purpose: in the overlap state — a row carrying account A's `localId` and `failed` `syncState` that
account B has downloaded — the menu today does exactly the wrong thing on both axes. `_allowDelete`
returns `true` for B with no authorship check at all, and `if (!isUnsynced)` hides *Remove download*
from B even though B genuinely holds the trail in their library. The destructive action is offered
and the safe one is hidden, both decided by a field read off a shared cache row. `library_screen`'s
long-press sheet has no guard at all, so its confirm copy ("the trail itself is not deleted") is
false. One predicate, `ownLiveCaptureProvider` (plan 02), fixes all three.

D-17 is not bookkeeping: neither existing suite constructs `availableOffline: true` alongside a
non-synced `syncState`, so they *structurally cannot fail* when the premise breaks. Task 1 adds that
fixture and confirms it fails against today's code BEFORE Task 2 fixes it.

Output: an owner-scoped delete gate, an owner-scoped download-family guard, a guarded library
long-press Remove tile, the overlap fixture, and a green full suite.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `TrailNotifier._readCached` → menu gate | The cached model is scoped only by `savedByUserIds`, so it can carry another account's `localId` and `syncState`. Every gate in this plan sits on the far side of that boundary and must therefore consult the row, not the model. |
| menu affordance → destructive executor | `_allowDelete` decides whether `_deleteTrail` → `TrailSync.deleteUnsynced` is reachable at all. It is the outermost gate on the CR-01 path. |
| confirm-dialog copy → store behaviour | `remove_download_confirm_body` promises "the trail itself is not deleted". A surface offering it where the store would refuse, or where the store would destroy a capture, is a repudiation defect. |
