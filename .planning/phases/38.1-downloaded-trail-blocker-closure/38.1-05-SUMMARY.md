# Phase 38.1 Plan 05: Owner-Scoped Delete Gate and Download-Family Guard (CR-01/CR-03 UI Halves, WR-12) Summary

**Closed CR-01's and CR-03's UI halves with the single `ownLiveCaptureProvider` predicate — `_allowDelete` no longer arms Delete off a bare `isUnsyncedState` read, `showDownloadFamily` replaces `!isUnsynced` so Remove/Update are offered to any library member who isn't the row's own capturer, and `library_screen.dart`'s previously-unguarded long-press Remove tile now hides under the identical condition — with the WR-12 overlap fixture proven to fail against the pre-fix code before the fix landed.**
