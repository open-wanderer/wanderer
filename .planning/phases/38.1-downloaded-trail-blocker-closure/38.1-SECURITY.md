## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|----------------|
| shared `TrailEntity` row → per-account UI model | `TrailEntity.id` is `@Unique(onConflict: replace)`, so a capture writer and a download writer for two different accounts target ONE row; `toModel()` copies owner-less fields with no owner filter | `localId`, `syncState`, capture bookkeeping |
| `TrailNotifier._readCached` → menu gate | Scoped only by `savedByUserIds`, so the cached model can carry another account's `localId`/`syncState` | Destructive-action gate inputs |
| Riverpod cache lifetime → account switch | `keepAlive`/family providers resolving `currentAccountId(store)` inside `build()` outlive the account that produced their answer if not registered for invalidation | Cached owner-scoped booleans/models |
| `accountId` string → filesystem path segment | Server-issued record id promoted to a path segment (`unsynced/<accountId>/<localId>/`) | Path segments |
| local row identity → destructive outcome reporting | A row-delete function's return value is what a caller uses to decide whether to delete files and report success | Delete outcome booleans/enums |
| library membership → row lifetime | "No library members left" and "this row is somebody's live capture" are independent facts about the same row | Row lifecycle decisions |
| go_router path parameter → widget | A route parameter fed a `firstWhere` with no `orElse` | Attacker/back-stack-influenceable id |
| planning artifact → future implementer | A decision recorded as true (Phase 36 D-10) was copied forward into destructive code paths without re-derivation | Design-decision text |
