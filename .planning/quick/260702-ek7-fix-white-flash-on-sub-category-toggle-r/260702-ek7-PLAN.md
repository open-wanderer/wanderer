<objective>
Fix the white/empty flash that appears on every (sub)category toggle or reorder in the settings screens.

Purpose: `category_preference_provider.dart` / `subcategory_preference_provider.dart` call `invalidateSelf()` inside their `upsert`/`reorder` methods. This flips the provider into `AsyncLoading<T>`. The shared `AsyncLoader` widget's data `switch` only matches `AsyncData<T>` and otherwise falls straight to `mockData` — which for both settings screens is an EMPTY list. Riverpod 3's `AsyncLoading` carries the previous value (via the nullable `.value` getter), but the switch ignores it, so the builder renders empty data inside a `Skeletonizer` until the refetch resolves — the visible flash.

Output: A one-line change in the single shared component so the previous value is preferred over `mockData` whenever available. Transparent to all 5 consumer screens; genuine first-load (null `.value`) still shows `mockData`.
</objective>
