<objective>
Let a user open an existing trail's recorded route inside the Flutter route planner, edit it, and save the edits back onto the trail being created/edited — without losing any other field (title, description, photos, visibility, waypoints).

This pulls PLANNER-02 (previously deferred to v2) forward as a quick task. It is a pure wiring job: every mechanism already exists in the codebase (pop-with-result navigation, the parsed track in `trail.expand.gpx`, the planner's `plannedGpxProvider` → `Gpx` synthesis). We add a seed path, a merge path, an edit-mode return path, and an entry-point button.

Purpose: Editing an existing route currently requires re-recording or hand-editing GPX; this closes that gap with the same route-planner machinery already shipped in v1.5.
Output: An app-bar button in `trail_create_screen` that round-trips the current trail's track through the route planner and merges the result back on Save.
</objective>
