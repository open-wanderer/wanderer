<objective>
Implement the missing route recorder: pure GPS track recording with no trail to follow. Recording is navigation minus the maneuvers/original-trail, so this reuses `NavigationScreen`, its breadcrumb/stats providers, the existing 3-option exit dialog, and the `buildDraftTrail` save-to-trail-create handoff — via a single `isRecording` flag threaded through four small branch points, a dedicated `/record` route, and an `ActiveSessionType.rec` resume path.

Purpose: Ship the "Record trail" entry point that has been a dead `_comingSoon` stub, using maximum reuse of already-working, GPS-driven navigation machinery. No new provider, no schema migration (the `ActiveSessionType.rec` enum and session-agnostic entity fields already exist), no new dependency.

Output: A working recorder reachable from the trail-source select screen that records a breadcrumb, lets the user pause/stop/save via the reused dialog, and survives an app kill via resume.
</objective>
