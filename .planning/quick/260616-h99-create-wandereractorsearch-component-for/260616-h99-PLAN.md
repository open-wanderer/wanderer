<objective>
Replace the broken author filter in the trail filter screen. Today the author field uses `WandererSearchBar`, which writes the raw typed text directly into `TrailFilter.author`. Because `author` is consumed as a Meilisearch clause `author = $author` (a PocketBase actor id), typing "john" produces `author = john` — a non-matching filter.

Build a new `WandererActorSearch` component that searches the `/search/actor` endpoint, shows actor results (avatar + name + handle) in a dropdown, and on selection writes the actor's PocketBase `id` into `TrailFilter.author` while displaying the actor's friendly name in the field. Support clearing the selection.

Purpose: Make the author filter actually filter by a real actor.
Output: New `wanderer_actor_search.dart` component; `trail_filter_screen.dart` wired to use it.
</objective>

Create a `ConsumerStatefulWidget` named `WandererActorSearch` (since it needs `ref` to read `apiProvider`). Import `flutter_riverpod`, `dart:async`, the `ActorSearchResult` model from `global_search_models.dart`, and `apiProvider` from `provider/api_provider.dart`.

Constructor params:
- `String? hintText` — placeholder text for the field.
- `String? initialAuthorId` — the currently selected actor id from the filter (may be empty/null).
- `String? initialAuthorLabel` — optional display name to seed the field when an actor is already selected (pass empty if none known).
- `required void Function(ActorSearchResult actor) onSelected` — fired when a result is tapped; the caller maps `actor.id` into the filter.
- `required VoidCallback onCleared` — fired when the selection is cleared; the caller resets `author` to empty.

State:
- A `TextEditingController` (dispose it in `dispose()`), seeded with `initialAuthorLabel` when non-empty.
- A `Timer? _debounce` (cancel in `dispose()`).
- `List<ActorSearchResult> _results = []`, `bool _isLoading = false`, `bool _showDropdown = false`, and `ActorSearchResult? _selected`.

Behavior:
- On text change: cancel any active `_debounce`; if the text is empty, clear `_results`, hide the dropdown, and invoke `onCleared` (and clear `_selected`); otherwise start a 500ms `Timer` (mirror the 500ms debounce in `wanderer_searchbar.dart`) that calls a private `_search(query)`.
- `_search(query)` is `async`: set `_isLoading = true` + `setState`, read `final api = ref.read(apiProvider)`, call `api.get('/search/actor', queryParameters: {'q': query})`, parse `((response.data['items'] as List<dynamic>?) ?? []).map((e) => ActorSearchResult.fromJson(e as Map<String, dynamic>)).toList()` exactly as in `global_search_provider.dart` lines 220-225. Wrap in try/catch; on error set `_results = []` (match the codebase pattern of swallowing search errors via `.catchError`). After completion guard with `if (!mounted) return;` then `setState` with `_isLoading = false`, the results, and `_showDropdown = true`.
- On selecting a result: set `_selected = actor`, set the controller text to the actor display name (`actor.username.isNotEmpty ? actor.username : actor.preferredUsername`), hide the dropdown, unfocus, and call `widget.onSelected(actor)`.
- Clear button: when `_selected != null` OR the field has text, show a trailing clear `IconButton` (Icons.close) that clears the controller, clears `_selected` and `_results`, hides the dropdown, and calls `widget.onCleared()`.

Layout: a `Column` (crossAxisAlignment.start) containing:
1. A `TextField` styled like `wanderer_searchbar.dart` (filled, rounded `OutlineInputBorder` radius 56, search prefix icon, `hintText`), with the conditional clear button as `suffixIcon`.
2. When `_isLoading`: a small padded `LinearProgressIndicator` (or `Padding` + `CircularProgressIndicator`).
3. When `_showDropdown && _results.isNotEmpty`: a bounded results container — wrap a `ListView` in a `ConstrainedBox(maxHeight: 280)` with `shrinkWrap: true`, rendering one row per result. Each row mirrors `_ActorTile` from `global_search_screen.dart` (lines 328-357): a `ListTile` with `CircleAvatar` (radius ~20) using `NetworkImage(actor.icon!)` when `actor.icon != null && actor.icon!.isNotEmpty`, else dicebear fallback `https://api.dicebear.com/7.x/initials/png?seed=$displayName`; `title` = display name; `subtitle` = `@${actor.preferredUsername}${actor.isLocal ? "" : "@${actor.domain}"}`; `onTap` triggers the selection behavior above. Do NOT navigate to a profile (that was `_ActorTile`'s job) — this dropdown selects a filter value.

Do not create a Riverpod provider for the search state — keep search state local to the widget (this is a transient UI concern, and the existing `WandererAutocomplete`/`WandererSearchBar` components are self-contained widgets). Reuse `apiProvider` only.
