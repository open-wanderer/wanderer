<objective>
Make `Auth.build()` in `app/lib/provider/auth_provider.dart` optimistic: when a saved user and a `pb_auth` cookie exist, return the cached `savedUserEntity` immediately instead of blocking startup on `_updateUserEntity`. Fire `_updateUserEntity(savedUserEntity.id)` in the background (unawaited); if that background refresh fails with a session-invalidating error (DioException, e.g. 404, or any error), call `logout()`.

Purpose: App startup / auth restoration currently blocks on a network round-trip, delaying the first render. Returning the cached user first makes startup instant while still refreshing user data and invalidating dead sessions.
Output: Modified `build()` method; no changes to `login()`, `refresh()`, or `_updateUserEntity` itself.
</objective>
