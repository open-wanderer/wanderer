<objective>
Replace the single-next-waypoint proximity check in `Navigation.onPosition` with along-track projection so that shortcuts (a user skipping one or more maneuvers) advance `currentManeuverIndex` past every passed maneuver in a single GPS fix, instead of getting stuck on a maneuver the user never walked within 30 m of.

Purpose: The current algorithm (navigation_provider.dart lines 83-111) only advances by one maneuver per fix and only when within 30 m of the *next* maneuver's begin-shape point. If a user takes a shortcut bypassing maneuver N, the app stays stuck on maneuver N indefinitely (research Failure mode A). Switchbacks where adjacent shape points are <40 m apart can also misfire (Failure mode B). Along-track projection (research Option B, the recommended default) is immune to both.

Output: An `onPosition` that (1) precomputes a cumulative along-track distance table when the response is set, (2) on each fix projects the GPS position orthogonally onto the route polyline to get an along-track distance from start, and (3) advances `currentManeuverIndex` to the highest maneuver whose cumulative distance is at or before the projected position (within the existing 30 m buffer). Forward-only and end-of-route invariants preserved. Extended test coverage.
</objective>
