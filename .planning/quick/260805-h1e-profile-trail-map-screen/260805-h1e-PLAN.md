<objective>
Add an author-scoped fullscreen map screen to the Flutter app, reachable from an AppBar
action in `profile_trail_screen.dart`, that shows exactly one profile's trails.

Purpose: the profile trail list answers "what has this person done"; it cannot answer
"where". This screen does, reusing the machinery `map_screen.dart` already proves —
clustering, the draggable sheet, search-this-area, tap-to-polyline — narrowed to one
author.

Output:
- An extended `/api/v1/trail/bounding-box` endpoint taking an optional `handle` (D-01),
  including the federated proxy and its world-view fallback (D-05).
- `mapTrailSearchProvider` and `mapClusterSearchProvider` converted to riverpod families
  keyed on `(authorId, filterId)` (D-02), with `map_screen.dart` and the existing test
  passing the global key.
- A corrected `TrailBoundingBox` model plus `profileTrailBoundingBoxProvider`.
- `ProfileTrailMapScreen` with local camera state (D-03) and the list screen's filter id
  (D-04), plus two extracted pure helpers shared with `map_screen.dart` (D-06).
</objective>

**Riverpod 3 family shape** (`riverpod_generator` 4.0.3, named params → record with named
fields). After Task 2 the two providers are addressed as
`mapTrailSearchProvider(authorId: <String?>, filterId: <String>)` and
`mapClusterSearchProvider(authorId: <String?>, filterId: <String>)`. Named, not positional,
so a transposed key is a compile error. No default values — riverpod_generator's family
templates have no default-value support.

**Server bounding-box payload** — snake_case: `min_lat`, `max_lat`, `min_lon`, `max_lon`,
`has_trails`. The unauthenticated and no-trails branches already return all-zero with
`has_trails: false`.

**`getActorResponseForHandle(event, handle)`** returns `{ actor }` where `actor` carries
`id`, `is_local`, `iri`, `preferred_username`, `domain`. The remote origin is
`new URL(actor.iri).origin`, and the remote's own handle for that actor is
`actor.preferred_username`.

**`ml.MapController.fitBounds({bounds, padding, nativeDuration})`** — real method in
maplibre 0.3.5. Never pass `Duration.zero` (the Android binding throws); use
`Duration(milliseconds: 1)` for an instant fit.

wrapping a horizontal `SingleChildScrollView` of opaque chips. Transparent background, so
it renders legibly directly over the map with no extra surface.

**`TrailCollectionMap({initCenter, initZoom, onMapCreated, onStyleLoaded, onMapEvent,
layers, children})`** — the shared map shell. It already buffers a style-loaded event that
arrives before `onMapCreated` and replays it once the controller is set.
