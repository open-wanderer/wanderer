<objective>
Shrink the turn-by-turn navigation-screen location puck. Replace the native MapLibre location component (which has no supported size control on either Android or iOS) with a custom, appropriately-sized Flutter marker plus a heading indicator, and replace `trackLocation`-based native camera-follow with manual `controller.animateCamera` calls driven from the position stream the screen already owns.

Purpose: The native puck is too large for hiking use and cannot be resized through the `maplibre` 0.3.5 public API. Dropping it for a custom marker (the pattern already used in `trail_map.dart` and `map_screen.dart`) is the only viable path, and because `trackLocation` only works by toggling the native puck's camera mode, camera-follow must move to manual `animateCamera`.

Output: All changes confined to `app/lib/routes/navigation_screen.dart`. `trail_map.dart` and `map_screen.dart` keep their existing (unrelated, non-heading) dots untouched.
</objective>
