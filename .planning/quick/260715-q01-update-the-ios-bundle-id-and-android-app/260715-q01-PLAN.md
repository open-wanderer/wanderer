<objective>
Rename the mobile app's native application identity from the Flutter-default
`com.example.wanderer` to `com.openwanderer.wanderer` across all iOS and Android
native config, including the App Group ids that the newly-added Share Extension
depends on.

Purpose: The share-extension feature introduced App Groups keyed on
`group.com.example.wanderer`. Shipping under the example default bundle id is
wrong for a real product and App Group ids must match the final bundle id for
the host app and extension to share a container. This is a pure find/replace
rename across native project config — no Dart, SvelteKit, or feature changes.

Output: Updated iOS pbxproj, both entitlements files, the setup doc, the Android
Gradle config, and the relocated Kotlin MainActivity package. Zero remaining
`com.example.wanderer` references in tracked source.
</objective>
